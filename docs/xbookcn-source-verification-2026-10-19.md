## 检查结果

- **搜索 / 空结果 / 作品身份**：完整书名命中首条；部分书名有结果；作者「顾盼若浅」20 条均为该作者；繁体「總裁」返回 15 条繁体标题（站点按原字匹配，不做繁简折叠）；特殊符号「NP）」有结果；随机串 `zzqqxx9999vv` 返回空列表且页面无结果容器。所有 id 均为 12 位十六进制。
- **搜索分页**：站点不支持 SSR 分页（`?page=2` 与第一页逐项相同），书源只取首屏 20 条，已在能力说明中标注。
- **全目录 / 顺序 / 下载前后快照**：267 章与 4 章样本均一次 SSR 全渲染；order 连续、ID 唯一、连续两次读取完全一致；下载前后各读一次目录并逐项比较，不一致即整本失败。
- **正文分页 / 编码 / 清洗 / 首尾**：站点正文无章内分页（无「下一页 / 本章未完」）；抽样 6 本 × 首/中/末章，0 个 C0 控制符、0 个 U+FFFD、0 个 `<img>`；正文容器为 `article.reading-text`，与导航/推荐区分离。
- **插图 / 封面**：站点无正文插图、无作品封面（`og:image` 是站点图标），记为**不适用**；书源 `cover=null`，不臆造占位图。
- **整本文件校验 / 真实生产下载 / 入库**：通过 `DownloadManager → DownloadWorker → XbookcnEpub` 真实下载 4 章短篇，EPUB 287,610 B，SHA-256 `f606bbbebb823d5a7661e96d76e4cb5f686ec50a83bbfcee412d76c099864f18`（一次样本；每次生成含 `dcterms:modified`，哈希会变），`GuestNovelIntegrity.epub` 通过，EPUB 内 4 章 `[001, 010, 029, 048]`、0 图。长章按 `MAX_CHAPTER_LENGTH` 拆为 11 物理章，`ChapterMerger` 合并回 4 逻辑章。
- **生产阅读器**：`ReaderScreen` 打开入库书，画面显示「001（续2）」、正文与「第 1/9 页 · 第 2/11 章 · 18%」，截图见 `evidence/xbookcn-reader.png`。目录跳转 / 上一章下一章 / 进度保存未逐项点按（通用阅读器逻辑，非本源实现）。
- **锁章 / 缺章 / 断网 / 取消 / 磁盘失败**：站点抽样未发现锁章或付费墙（6 本首/中/末章均可读）；404 与非法 ID 明确返回错误；空章与「购买本章」文案在单测中明确失败。断网、取消、磁盘满、429/5xx 注入未执行。
- **更新成功与失败**：`refreshNovelDetail` + `NovelDownloadStore.baseline` 已接线；未构造真实更新样本，旧数据保留路径未实测。
- **fixture 与实网执行数**：
  - JVM fixture：`XbookcnSourceTest` 6 项 + `XbookcnSnapshotTest` 3 项（真实页面离线快照），**9/9 通过**。
  - 设备实网：`XbookcnSourceDeviceTest` 5 项（注册、搜索、目录、拒绝路径、下载+入库+阅读器），**5/5 通过**。
  - 未执行：全量 JVM / androidTest 套件、`assembleRelease`、实体手机。
- **最终 APK / 签名 / SHA-256**：未打包，未验收。本轮只验证 debug 安装包的真实链路。

## 结论

- **通过范围**：搜索、详情、完整目录、在线正文、整本 EPUB 生成、完整性校验、入库、生产阅读器渲染；免登录；不依赖成人源开关。
- **不通过 / 未测范围**：断网与取消、磁盘不足、429/5xx 注入、连载更新回滚、目录下载期间变化、真实设备（非模拟器）、Release 构建与签名、搜索分页（站点不支持）。
- **已知例外**：站点按原字匹配，繁简不互通；搜索只有首屏 20 条；无封面、无正文插图；长章入库拆分（阅读器合并显示）。
- **是否进入生产注册列表**：进入；`supportEbook`、`supportOnlineText` 均可用，未禁用任何已声明能力。
