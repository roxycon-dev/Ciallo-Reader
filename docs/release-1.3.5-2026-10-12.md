# Ciallo Reader 1.3.5

版本 1.3.5 / 216，Android 7.0+，arm64-v8a。针对“荣耀 200 Pro 每页至少 2 分钟、容易失败、希望后续页预生成”的反馈，改用移动端速度优先方案。用户本轮已允许更换、量化模型等取舍；本次没有手机连接，不声称手机 5 秒达标。

## 执行变化

- 模型从 V1 黑白漫画 ESRGAN 改为原作者同一仓库的 **IllustrationJaNai V3denoise SPAN-S 2x / 30k**。原作者将它定位为轻度劣化彩色插画的较快模型；与旧模型的训练、算法和画质均不同，界面改称“JaNai 极速”。[原作者 3.0.0 预发布](https://github.com/the-database/MangaJaNai/releases/tag/3.0.0)，[派生说明与许可](vendor-licenses/MangaJaNai/README.md)。
- 模型 1,673,288 B，约 1.6 MiB（旧模型 67,191,396 B），410,701 个参数、22 个卷积算子。随 APK 分发，离线校验复制；成功后只清理应用私有目录中的旧 V1 模型，无首次联网下载。
- 原 FP16 导出转换为 FP32，修正符号输出尺寸并使用兼容的 opset 18。CPU / 最多 5 线程动态调度 / XNNPACK 按真实首块择优，候选至少快 15%，输出须有限且最大误差 ≤0.03、平均误差 ≤0.003。避免可能长时间阻塞、无法通过 RunOptions 截止的 NNAPI 驱动编译；生产版本没有强制 GPU。
- INT8 的 48 个合成线条、文字、网点、颜色和噪声样本校准，在独立样块上最大误差明显、PSNR 约 20–28 dB；U8/U8 和缩小权重范围候选仍没有通过质量评估，未分发 INT8。转换工具默认只生成正式 FP32 模型。
- 根据实际分块耗时和剩余预算选择网络输入，最多 90 万像素 / 1400 长边，128 px 核心 + 24 px 边缘。网络最多约 3.2 秒预算，并用 1.4 安全系数；这会降低神经网络处理分辨率，不能称为全原分辨率超分。
- 输出仍由原始图像细节构成：`原始细节 + (缩放后的网络输出 − 同尺寸网络输入) × 强度`，保留原图透明度。文字和一像素细线不会仅靠小图放大重建。最终输出仍受既有 400 万像素 / 3200 长边上限约束。采用两个 48 行带状缓冲，减少全页临时副本。
- 页面推理从开始约 4.3 秒设置 RunOptions 终止，留出合成时间；超时和失败保留可读原图，不缓存或记录为成功 AI。网络、图片解码、热降频和原生会话创建不构成手机 5 秒硬保证。日志 `aiComplete=true` 只在全部所需网络图块和细节合成完成后输出。
- 当前页优先，随后串行预生成最多 3 个前向显示槽；不同页共享一套会话和缓冲，跳页取消过期任务，正在生成的下一页转为当前页时复用同一次任务。横向/条漫窗口均接入；仍遵守在线 Wi-Fi 预加载设置。
- 完成页沿用无损磁盘缓存，新模型指纹隔离旧结果；预生成内存窗口最高 64 MiB，并受堆预算约束。一个精确浮点图块缓存约 0.87 MiB；空闲 60 秒、退出阅读或内存压力时释放引擎。极简档继续关闭增强和后续预生成。

## 完整页桌面测试

桌面 CPU / 4 线程 / Python ONNX Runtime 1.29.0；APK 为 Android ORT 1.28.0。在同时运行构建测试的机器上测量，包含读图、创建 CPU 会话（冷页）、缩放、全部网络图块、拼接和原图细节合成，不含 PNG 写盘或 Android 后端择优。没有成品缓存，也没有图块缓存；每个列出的图块均实际推理。Pillow 采样与 Android Canvas 不完全相同，这些结果仅用于桌面方案验证，不能外推荣耀或任意手机。

| 页 | 输入 → 神经网络输入 | 实际推理块 | 含处理整页耗时 |
| --- | --- | ---: | ---: |
| 彩色漫画 002（冷会话） | 1800×1748 → 620×603 | 25 | 3.417 s |
| 彩色漫画 003（热会话） | 1275×1800 → 383×543 | 15 | 2.340 s |
| 彩色漫画 004（热会话） | 1275×1800 → 356×504 | 12 | 1.871 s |
| 密集线条合成页（热会话） | 1200×1800 → 372×558 | 15 | 2.288 s |
| 中文漫画黑白化 JPEG（冷会话） | 1200×1694 → 478×676 | 24 | 2.439 s |

实际漫画来自《小辣椒与萝卜头》第 28 集《盛宴》：David Revoy 创作，Ran Zhuang 中文翻译，[原作和署名](https://www.peppercarrot.com/cn/webcomic-sources/ep28_The-Festivities.html)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。彩页按比例限制为 1800 长边；黑白样本经过灰度、缩小和 JPEG 编码，属于测试派生。没有《别当欧尼酱了》原图，不能冒用该漫画成绩。

目视检查完整页和中文文字裁剪；字符仍可辨认。原图细节并不等于完全无画质变化：轻模型、低分辨率网络修正和去噪都会改变效果。256×256 实页采样的 4 块边缘，与同一新模型整图一次推理比较，FP32 最大/平均误差均为 0（验证 24 px 边缘覆盖网络感受野，不代表与旧 ESRGAN 等价）。

复现：

```text
python tools/prepare-janai-mobile.py IllustrationJaNai_V3denoise_onnx.zip REPORT_DIR
python tools/benchmark-janai-mobile.py MODEL.onnx REPORT_DIR --input LICENSED_PAGE.jpg
```

Android `MangaJaNaiPerformanceDeviceTest` 使用 APK 内置权重，直接运行完整页增强，分别记录冷会话和热会话，断言每页 ≤5000 ms；超时返回原图不算通过。支持 `mangaPage`（应用私有 files 内实际页）或默认 1200×1800 合成页。该设备测试编译通过，**没有运行**；本次 `adb devices` 无设备。荣耀 200 Pro 的实际整页速度、峰值内存和《别当欧尼酱了》画质仍待用户设备验证。
