# Ciallo Reader 1.5.0

这一版只做两件事：把书库里那本默认存在的《Ciallo Reader使用指南》去掉，以及让书架长按进入多选时不再触发抽纸动效。

## 移除内置阅读指南

新装的软件不再往书架里塞这本书。已经存在的安装也不用手动删：下次启动时 `checkAndSeedDefaultBooks` 会找到 `filePath = ciallo_guide_novel` 的那本书，连同它的章节和指向它的阅读记录一起清掉，和清理历史占位书走同一套逻辑，不会留下孤儿行。

这里刻意没有直接把整段初始化代码删掉了事——只删「新建」部分的话，老用户书架里那本还会一直在，等于没修。

## 长按选中不再抽纸

长按书籍进入多选属于「选中状态切换」，不是「点击后打开内容」，抽纸动效在这里既慢又抢戏：一次长按会把整张纸面从按钮缝口拉出来，选中反馈反而被盖住。

现在这两层各自使用独立的弹簧动效：

- 顶部多选栏：从顶部 `slideInVertically` + 淡入，退出反向滑出；
- 底部悬浮操作栏：从底部 `slideInVertically` + 淡入，退出反向滑出；
- 进入用刚度偏软的弹簧（阻尼 0.86），退出用 180ms 的收束，避免弹跳过头。

抽纸封装本身没有改动：书籍卡片的选中反馈、操作栏里的按钮、其余弹层仍然走统一的 `PullOut*`，只是选中态这个动作不再认领纸面。

## 本轮验证

- `:app:compileDebugKotlin` 通过。
- 相关单元测试与设备用例在打包前执行，结果见本次 release 附件。
- `BookRepository.checkAndSeedDefaultBooks` 的清理分支与历史占位书清理保持同一套 DAO 调用顺序：删章节 → 置空阅读记录里的 bookId → 删书。
