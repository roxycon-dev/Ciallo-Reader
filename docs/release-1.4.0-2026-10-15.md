# Ciallo Reader 1.4.0 · 2026-10-15

发现聚合、状态筛选与两处书源故障修复。

- 移除「点击」入口；保留原站人气排行中的真实统计。
- 聚合不再被第一个返回的目录触发栏目切换、取消其他源；兼容不完整原站目录，实际探测可用入口。每个启用漫画源独立请求、到即展示，支持展开查看参与数量、失败和无数据原因。
- 更新聚合使用源内位置归一化，避免只提供同一天日期的长列表霸占前列；同一作品跨源合并，使用同维度数据。
- 连载、完结、未知使用同一数据集的本地筛选；跨源同作品只展示符合所选状态的版本，保留作品标识。完结榜严格过滤；详情提供的明确状态优先于榜单推断，不把连载强行标成完结。
- 分类和状态缺失时后台读取原站详情，每源每页最多 8 本，5 分钟去重；先展示列表，不等待所有详情。未知状态不伪造，数量仍仅代表已加载作品，因此「连载+完结」不包含未知和停更作品。
- 切换状态不创建新的网络栏目；复用现有 32 栏目分页会话、有效持久缓存和滚动位置。分类、栏目切换保持各自分页上下文。
- Hitomi 的 Android base64 解码结果规范化成真正的 ArrayBuffer，修复 DataView 类型异常；桌面验证桥也改成 Android 同样的字节数组返回，防止测试掩盖运行时问题。
- 爱漫画沿用公开阅读线路和线路切换。优先系统证书验证，补充官方 ISRG Root X2 链验证，让旧 Android 能验证正常续签的新证书/新公钥；当前源站证书 2026-10-14 到期，已知公钥仅提供到期后 14 天缓冲，仍验证域名。没有全局关闭 TLS 验证。源站持续不续签、改变线路或停机仍需维护，不能保证永久在线。

本次验证只针对上述变更：

- 66 项相关 JVM/Robolectric 回归：聚合、去重、排序、分类状态、缓存、界面及 Hitomi 脚本载荷。
- Hitomi 实际生产脚本在线验证：更新、25 本第二页新作品、周榜、中文分类和冷恢复分类第二页；解码桥与 Android 字节数组类型一致；额外完成真实详情→3 张页面→首张 WEBP（HTTP 200 / 99,722 B）链路。
- 爱漫画实际目录（30 本）→详情→章节（75 张图片）→首图 HTTP 200 / 132,454 B；生产 Kotlin/OkHttp 客户端验证 HTTPS 目录、续签缓冲边界及源隔离；测试 CA 链换公钥成功，过期新公钥及无关自签证书被拒绝。
- 相关离线脚本验证原站排序选项、周/月、状态缺失和分页游标恢复。
- 正式包签名、覆盖 1.3.11 升级条件、版本、资产、ZIP CRC 和 16 KiB 对齐核验；未启动模拟器，未执行无关全量审查。
