# 发现页与小说书源修复（2026-10-20）

## 改动

- 发现页“查看来源”和错误详情统一进入有独立滚动区、关闭键与重试入口的面板，避免 22 个源的诊断文本挤占作品列表。360dp 小屏、130% 字体检查最后一项、关闭键和重试按钮均可达。
- 19漫画更新页本次实测返回 1041 部作品、约 56 万字符、7445 个元素，原先估算后超过 4 MiB 的 DOM 被误拒绝。保留 2 Mi 字符输入上限、最多 8 个文档、句柄随文档释放及总量淘汰机制，将 DOM 总预算调整为 8 MiB。
- HTTP 451 显示“源站限制了当前地区的访问”，并归入网络错误。这个改动改善错误说明，不能解除源站的地区限制。
- Novelia、Wenku8 Library、爱下电子书及番茄请求使用有上限、可取消的重试；IO 中断和 HTTP 408/429/5xx 最多重试两次，403、解析错误和取消不重试。其他公开 HTML 小说源原有的有限重试保持不变。
- 新增“番茄小说（公开聚合）”：番茄公开搜索与目录、书荒殿检索补充、张老师API正文；支持数字书籍 ID、官网书籍链接、在线阅读和逐章 EPUB 下载。小说详情为支持在线阅读的源增加入口。
- 番茄目录的网页试读限制标记 `isChapterLock` 与付费标记分别处理；仍拒绝 `needPay`、付费出版物和付费故事。正文接口独立校验失败、空白、乱码、私用区字体字符和常见不完整提示；失败章节不会拼进已完成 EPUB。
