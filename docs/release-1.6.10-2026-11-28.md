# Ciallo Reader 1.6.10 · 爱丽丝书屋改版重写与登录体验修复

版本 **1.6.10 / 271**，2026-11-28，Android 7.0+，ARM64。

## 爱丽丝书屋：站点换新，书源重写

爱丽丝书屋在 2026-11 把站点整体重写成了 Next.js（发布页 `alicesw.net` 只做域名公告）。
旧的 PHP 页面结构在线上已经不存在，所以原书源会表现为"完全失效"——不是线路全挂了，
是解析对不上了。本版按新站契约重写：

- 搜索 / 详情 / 目录 / 正文 / 分类全部走站点自己的 `/api/v1/…` 接口，页面 HTML 作为兜底；
- 线路池更新为 2026-11-28 实测可用的 `alicesw1/2/4/5/6.homes` 与 `www.alicesw.tw`；
  `alicesw.net` / `alicesw.click` / `alicesw.club` / `www.alicesw.quest` /
  `爱丽丝.als1007.space` 是发布页，只用来发现新域名，探活时会被明确排除；
- 作品用内部 id、章节用 `chapter_no`。

已知限制：榜单页的 tab 是客户端渲染、服务端只返回默认热度序，所以发现页的「热度榜」是
站点默认榜（带名次、可翻页），「收藏榜 / 最近更新」走接口；站点没有热议与点击维度。

## Z-Library 登录：不再只有一句"登录失败"

- 失败原因会区分：邮箱/密码被站点拒绝、站点要求人机验证、请求过于频繁（429）、服务端
  错误（5xx）、所有节点都连不上、登录接口已改版，并给出对应建议；
- HTTP 登录（rpc.php / eapi）被站点验证拦住时，自动改用**内置网页登录**：独立的**全屏**
  登录页面（不再挤在弹窗里，页面可正常上下滑动），自动填入账号密码、代点 DiamWall
  复选框，遇到验证码在页面里手动完成，成功后同步 Cookie 并自动关闭；
- 登录窗口移到屏幕中间，键盘弹起时随之上移，不再被输入法盖住。

## 密码箱

设置 → 数据管理 → 密码箱：加密保存需要登录的书源账号。登录时自动填入、成功后自动更新；
同签名覆盖安装与升级都会保留。按设计不进入备份与设备互传，换设备需要重新录入。
