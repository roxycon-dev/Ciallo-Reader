# 交互与转场审计（按钮清单）

## 1.6.0 合并与回归处理

- 以 1.5.16 主分支作为第一父提交，保留统一下载、批量导入、自动备份、书源和 EPUB 插图实现。UI 迁移提交不包含旧工作区的源码、下载后端实验或本地素材删除。
- 玻璃半窗使用完整窗口尺寸并显式读取导航栏／键盘边距。清缓存只走空间释放反馈。Dock 使用一个与标签对齐的按压指示器，3D 书架锁定横向手势。
- 高画质保持实时模糊。极致档在支持的系统与自定义壁纸上额外启用边缘折射。保留实时圆角、透明度、主题色、透视和压力调整。缓存玻璃轮廓，避免滚动帧反复分配路径。
- Issue #7 对照参考仓库的宽屏限宽。书库和发现居中，发现网格按宽度使用 2／3／4 列。漫画设置的图片预加载支持自动或 0–12 张，独立于画质和双页排版。
- Roxy 庆祝 GIF 由现有角色素材编排，保留减少动态效果及低版本系统的静态路径。

### 验证记录

- 同一 x86_64 Android 35 模拟器、相同书目和壁纸，两个调试包各预热一轮后按同序点按 18 次 Tab。`gfxinfo` 显示 P90 为 101ms → 77ms，慢帧比例为 28.2% → 24.5%。交付包按同序列复测为 P90 81ms，慢帧比例 29.3%。P90 在两次取样中均下降，慢帧比例波动，流畅度仍待优化。Flutter 真机同条件对照仍待完成。
- 书架搜索收起的保留布局实验在四次取样中 P90 为 53–85ms，改前为 46–61ms。该实验已撤回，覆盖时继续暂停布局。此结果不作为搜索退场已优化的证据。
- `TabBarMotionTest` 像素断言覆盖半透明场景的裁剪交界，另外验证 Tab 复访保留组合。`WenkuSheetLifecycleTest` 覆盖关闭期间保留、重复触发忽略、回调顺序。Android 设备夹具验证书源选择只打开一次管理路由，小说卡先打开简介、点击下载才请求文件。
- 最终调试包通过 6 个定向回归，覆盖透明页裁剪、发现的滚动恢复与长按重开、面板与菜单关闭、统计历史菜单。模拟器走通上表新增的发现、统计和设置路径，期间无新增崩溃记录。
- 统计日历在同一 x86_64 Android 35 模拟器上用两个调试包预热一次，再各做四组下月与上月切换。单轮 `gfxinfo` 取样为 P90 46ms → 38ms，慢帧比例 28.12% → 21.68%（352 帧 → 369 帧）。Flutter 发布包和真机仍需同条件复测。
- 阅读器本轮 12 个定向单元回归与 2 个漫画设备用例通过。漫画设备夹具启动时同时清零该测试章节的单独续读位置，保证重复运行从第一页进入。
