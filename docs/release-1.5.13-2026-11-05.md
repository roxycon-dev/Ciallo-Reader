# Ciallo Reader 1.5.13 · 抽纸过渡优化

版本 **1.5.13 / 255**，2026-11-05，Android 7.0+，ARM64。

- 保留原有抽出、柔性收颈和缩回按钮的形变、弹簧参数及网格精度。
- 修复低帧率下动画时间被拉长，尤其是关闭末段滞留的问题。
- 背景模糊与压暗随窗口同步淡入淡出，结束前逐渐退净；多层窗口保留各自效果。
- 复用重复的形变计算、模糊效果和窗口属性，减少无效工作。

## 原因与调整

旧解析弹簧每帧最多推进 33 ms；实际帧间隔超过这个值时，丢失的时间不会计入动画，导致越卡越慢。解析解本身可以一次计算任意经过时间，现改为实际帧时间推进，不补算多个小步，反向操作仍保留当前位移和速度。

原生背景模糊之前保持全强度直到 Dialog 移除。现在由窗口级生命周期同步驱动模糊、原生 dim 和 Compose 遮罩，使用同一端点平滑曲线。半物理像素精度合并模糊更新、缓存效果；多 owner 取最大有效半径，避免正在退出的子窗口清掉父窗口。窗口布局、动画和 dim 的初始配置也不再随内容重组反复写入。

## 对照测量

同一 Android 15 x86_64 模拟器、NVIDIA host 渲染；同一真实玻璃弹窗、同一 debug 驱动，分别执行 4 次，排除首次预热，以下为剩余 3 次中位数。

| 条件 | 指标 | 1.5.12 | 本版 |
| --- | --- | ---: | ---: |
| 正常运行 | 打开 | 1026 ms | 1060 ms |
| 正常运行 | 关闭 | 799 ms | 819 ms |
| 每帧人为阻塞主线程 60 ms | 打开 | 2156 ms | 1314 ms |
| 同上 | 关闭 | 1873 ms | 1002 ms |
| 同上 | 最后 5% 进度到完成 | 915 ms | 142 ms |

正常帧率下关闭约 0.8 秒，保持原节奏；低帧率下消除了额外的时间拉长。背景绘制记录均为 1 次，背景过渡不引起内容逐帧重组。固定形变三角项复用后，本机 JVM 微基准中位数由 7619 ns 降至 5559 ns / 次；这不是手机帧率或整机性能百分比。

这是可控掉帧条件下的计时验证，不是低端手机实测，不能据此承诺所有手机达到 60/120 FPS。未改变质量档位或自动关闭抽纸、玻璃效果。
