# Ciallo Reader 1.5.9 · 哔哩与 19 漫画连接修复、安全加固

版本 **1.5.9 / 251**，Android 7.0+，ARM64。

哔哩漫画修复脚本 Cookie 与应用 Cookie 重复拼接、搜索凭证失效后无法续取的问题，公开请求增加直连与代理回退。书源管理新增「验证」入口；网站仍拒绝当前会话时，提示完成站点验证。验证后的浏览器身份同时用于页面和图片，不再在读图时覆盖成另一套身份。

19 漫画在移动站连接失败、空响应或页面异常时尝试同站 `www.sxchex.com` 线路，并在当前会话内优先使用成功线路。保留已有作品、章节标识与书架记录。

整章下载把完整响应体读取纳入重试，避免已收到 HTTP 200 响应头、随后连接中断时直接结束下载。仍保留单张 32 MiB 限制、取消与整章完整性检查。

## 安全边界及报毒状态

阅读图片、封面和下载共用的 HTTP 传输拒绝通过明文 HTTP 发送 Cookie、Authorization 或 Proxy-Authorization，包括重定向；自动 Cookie 读取仅用于 HTTPS。去掉下载器向新地址回填原地址 Cookie 的行为。匿名 HTTP 图床仍可访问，正常 HTTPS 登录会话仍可使用。网站验证窗口禁止文件访问、内容提供器访问和混合内容。

既有 [Issue #3](https://github.com/roxycon-dev/Ciallo-Reader/issues/3) 的历史反馈涉及 `a.gray.BulimiaTGen.h` 与 `a.gray.sexBLTWbindsnake`，不能据此确定 1.5.8 的当前检测原因。1.5.7 与 1.5.8 的发布证书、权限集合相同；原生库的代码段也一致，差异只有构建标识。没有发现之前证书校验修复被撤回。

**本版进行了实际安全加固，但未确认系统报毒已消除。** 按用户要求不启动模拟器、不进行新的查杀测试；缺少用户原机检测结果。签名、证书校验与现有功能保持。

## 验证范围

仅复验本次报告的哔哩和 19 漫画。使用主机运行实际内置源脚本，匿名 HTTPS 请求、整章图片下载及逐页解码；Android 阅读器界面、后台入库与原机检测未在本轮复测。此前其他源的通过记录沿用，不重复访问；Picacg、vomic、MYCOMIC 仍按用户授权排除。

主机实网结果：哔哩《勇者鬥惡龍 達伊的大冒險 勇者阿邦與獄炎魔王》第 52 话 **46/46 页**；19 漫画《百万勇者传说》第 1 话 **27/27 页**。共 **73 页**完成下载解码，并离线逐页复核保存文件的 SHA-256、尺寸及解码。连接中断曾在测试中实际出现；最终整章结果包含重试后的完整文件。

19 漫画还在测试端模拟主线路不可用，实际通过备用域名完成搜索、详情、目录和阅读页解析；27 个图片地址与已下载文件完全一致，没有重复下载。

离线源回归覆盖备用域名切换、无效页面拒绝、作品标识保持、哔哩过期搜索票据续取和 403 验证提示。**11 项 JVM 安全与下载回归全部通过**：证书及主机名校验、有效 HTTPS 会话、HTTP 凭据与重定向拦截、Cookie 合并，以及响应体截断后的完整重试。原始记录及测试脚本随 Release 附件提供。
