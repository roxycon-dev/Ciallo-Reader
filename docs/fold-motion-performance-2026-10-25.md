# 动效与折叠屏优化验证 · 2026-10-25—26

交付版本 **1.5.2 / 244**。保留布局、清晰度、材质、动画曲线、时长、幅度和触觉参数；成人源按用户追加要求固定启用，六次解锁及专用开关卡片已移除，旧关闭值不再生效。

## 已实现

- 按钮阴影的逐帧状态在绘制阶段读取，轮廓与签名按尺寸缓存，仅在精确浮点高度变化时刷新两层阴影。静态高度接口保留。
- 开关缓存画笔和渐变；滑条复用渐变、矩阵及几何缓冲，隔离父层重复绘制，同值更新不再唤醒动画。尺寸或密度变化时重新建立相关数据。
- 阴影竖向模糊保留原舍入与边缘复制，按连续行遍历；数组池每桶最多四块，总预算 4 MiB，借出期间不共享，LRU 控制容量。
- 玻璃保留原始 AGSL 程序，缓存未变化的形状、预处理和效果数据；按压参数变化仍生成新的效果快照，实时背景保持可更新。快速反向操作保留动画速度。
- 弹层预计算弹簧常量并复用坐标缓冲；同章窗口重分页期间保留已有页面，用正文字符位置恢复阅读锚点，过期尺寸结果不得发布。

## 功能及像素

相关 JVM 回归 **78 项通过，失败/错误/跳过均为 0**。包括四种按钮共 32 个按压/释放关键帧、15 个开关帧、576 个滑条帧、10,000 步弹层物理轨迹，以及分页缓存和成人源固定开启的三项回归。两项仅用于计时的微基准与功能测试分开运行。

设备路径检查包含动态玻璃、快速释放/反向、密集控件、字号与触控区域、折叠及窗口变化。固定控件截图与原始实现对照；最终结果、APK 校验和及各套件计数随发布附件提供。[验证数据与图片](https://github.com/roxycon-dev/Ciallo-Reader/releases/download/v1.5.2/PerformanceEvidence-v1.5.2.zip)。

这些像素证据覆盖固定场景，不是全部页面或所有三星设备的逐像素认证。折叠回归使用 API 35 的 7.6 英寸折叠配置，同时改变设备姿态与 884×2208 / 1768×2208 窗口区域；不冒充三星 One UI 的真实分屏结果。

非调试 R8 构建、AOT speed，工作线程 CPU 时钟；每个尺寸先预热，再进行十组成对、交替顺序的测量，每样本 100 次竖向 pass。每组先检查新旧输出及缓冲尾部逐位一致。

## 未保留的实验与验收边界

减少 shader 空槽位运算的方案曾通过 54 组像素对照，但没有可靠整体 GPU 收益，已撤回，交付继续使用原 shader。两版精确 JNI 阴影内核也因没有可靠整体 CPU 收益撤回，正式 APK 不含实验动态库。

过程完成过十组成对发布式采样；后续发现可继续消除的阴影组合开销并调整了实现。这批旧候选数字不能冒充最终 APK 的加速幅度。模拟器多次出现 system_server、图形驱动和 ADB 异常，失败/不完整批次不作为有效结论。按用户加速交付的要求，最终版本未完成稳定的十组成对整页 CPU/GPU 验收。

**CPU/GPU 占用降到原来 10–20% 的目标尚未得到证明，也未声称达到理论最优。** 剩余开销包括实时模糊折射、滑条软件位图重绘与上传、必要的布局/文本测量，以及模拟器图形转发；页内同步文本测量只能在分块间取消。更多真实业务负载和三星真机数据仍需补测。

[Android 性能构建建议](https://developer.android.com/topic/performance/benchmarking/macrobenchmark-overview)与[模拟器测量限制](https://developer.android.com/codelabs/android-macrobenchmark-inspect)。复现入口见 [验证工具](../tools/fold-motion/README.md)。

## 既有失败

`realManualAndCacheKeepOneHeaderAndReopenAfterAnEarlyDismiss` 在面板打开 64 ms 后点击外部的步骤，在原始 APK 同样超时，未算入通过项。`ReaderGlassPolishTest` 的固定 500 ms 等待在基线也失败，仅测试改为在 2 秒内等待实际关闭并保留首帧可见断言；产品动画时长未改。
