## 本次更新

- **触控分区**　漫画和小说按阅读模式分别保存点按与滑动动作，可在保存前试读。拖动分区可移动位置，拉动四边或四角可缩放。「全屏调整」收起工具栏，便于把分区拉到阅读区边缘。
- **滑动与翻页**　修复自定义分区后无缝滚动失效的问题。设为「跟随阅读模式」的区域，在状态栏显示时仍可正常滚动。仿真卷页回弹期间也能响应下一次拖动。
- **收藏列表**　「我的书架」使用 3D 布局时，点按「我喜欢的」列表中的收藏可正常打开。
- **漫画源导入**　在「管理书源 → 导入书源 → 导入漫画源 JS 文件」批量选择 Venera 兼容脚本。可预览名称和版本，选择安装或替换。刷新仓库时会保留本地导入的漫画源。已启用的源可在「发现」展示其提供的栏目。
- **漫画翻译**　默认免 API Key，开启「整页自动翻译」即可把日文、英文和韩文译成简体中文。匿名服务限流时会尝试备用翻译，自定义 AI 接口仍可手动选用。
