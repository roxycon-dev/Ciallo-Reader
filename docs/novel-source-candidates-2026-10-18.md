# 中文小说书源候选调查（2026-10-18）

本轮按用户要求先调查、列候选，等待用户选站。未修改应用书源、名称或安装包。

## 结论与验证范围

- 没有证据支持任何一个站或下列组合涵盖所有轻小说、国内网文或同人文。未翻译、未公开、删除、锁定和站点独占作品会造成缺口。
- 国内连载追更新应以作品首发平台为基准。聚合站的“更新最快”宣传不能证明与首发同步，本轮未做连续更新延迟测量。
- 候选网站不等于已经可导入本应用的书源。本轮做网站检索、公开页面检查和本机未登录 HTTP 抽查；未完成 Android 搜索、目录、正文、下载端到端验收，未验证任何付费章节。
- 中文包含简体、繁体。人工翻译、出版译本、机器翻译须按作品分别标注，不能以网站名称代替译本说明。
- 主机 HTTP 200 只证明对应入口返回成功；小型跳转页、前端壳、登录页和不完整正文不能视为阅读成功。搜索引擎的抓取结果与本机网络结果可能不同。

### 现有 Novelia 接口抽查

现有 `AutoNovelSource.kt` 使用 `https://n.novelia.cc/`。该网页当前标题本来就是“轻小说机翻机器人”，并非项目自行杜撰的名称。若用户不接受该名称，可以用域名标识 `Novelia（n.novelia.cc）`，应明确它是显示简称，不能冒称为上游“成为小说家吧”或 Kakuyomu。

本轮本机请求：

- 首页 200。
- Re:Zero 小说详情 200、合法 JSON，返回 797 个有编号目录项。
- 目录末项 `797` 的章节接口 200，415 段原文，Sakura 和有道数组均 415 段，按本次非空逐段抽查没有缺译段落。
- 搜索入口返回 200；未因此宣称所有关键词、所有作品均能正常搜索。

这证明此次抽查时该服务部分接口可用；不能据此否定用户手机上的连接失败，也不能确定失败原因。本轮未做设备端复现、完整电子书下载或与日文原站最新目录对比。

1. 中文日轻：先选 A1 哔哩轻小说、A3 轻之国度，保留检查 A5 Wenku8 Library；A2 轻小说文库和 A4 真白萌值得作为访问/登录专项候选。A6 深夜读书会补 EPUB。

3. 同人：C3 晋江、D3 刺猬猫、D4 飞卢、D5 SF 侧重长篇；D1 AO3、D2 LOFTER 补圈层和 CP 文；D6 话本补角色向和对话体。不同站不能互相代替。
4. 追首发更新：根据实际常读作品选择 C1、C2、C3、C4 等对应首发站，先验证账户权限内正文，再谈应用内接入。
