# 1.2.7 阅读与收藏修复

版本：1.2.7 / 208。沿用正式签名，保留 1.2.6 历史安装包与 Release。

## 双指缩放

- 分页、磁吸、仿真放大层：速度采样使用累计画面平移，替代单根手指的绝对坐标；指针数量变化清空速度历史。
- 发生过捏合缩放的手势松手后只处理边界回弹，不把手指向两侧展开的速度转成画面惯性；新的单指平移仍可惯性滑动。
- 连续滚动阅读使用的 ZoomState 同样排除缩放手势，并以平移增量采样，避免抬指时质心变化产生假速度。

## 多选底栏

- 底栏完整布局范围接收触摸，包含按钮间空隙、外侧留白与禁用按钮；四个按钮各占相同宽度，保留液态玻璃和进出动效。
- 书架手势宿主尊重已消费的按下事件，并在后续事件被其他控件接管时退出；底栏按钮不会同时切换背后图书的选中状态。
- 未被覆盖的图书继续支持点击、长按、多选和拖拽；书架与收藏的选中集合仍独立。

## 收藏警告与链接

- 三角警告表示来源已移除或停用。超时、登录问题和一次更新请求失败不再直接认定书源失效；取消请求不回写失败状态。
- 旧版本标记为失效的收藏进入检查时优先复核；成功打开章节目录也立即修复状态。健康状态只更新对应主键，不复活已删除收藏或覆盖分类。
- `js_copy_manga` 使用作品 `path_word` 对应网页 `/comic/{path_word}`，无需再次拉取章节。已核实《百合甜心》为 `baihetianxin`，公开页面返回作品标题。
- 同名的拷贝漫画和漫画人收藏按 `(sourceId, comicId)` 分别分享，允许共存。
- JS 源提供的相对详情链接按其运行时 baseUrl 解析；不把 API 地址当成网页。公开链接继续缓存并支持离线分享。
- 确实没有公开页面的来源使用 `ciallo://detail` 详情链接，明确标注接收方需安装 Ciallo Reader 并启用相同书源；支持冷启动与新 Intent，校验来源、编号和参数，不包含登录凭据。不同接收应用对自定义协议的点击支持可能不同。

公开路由依据：[Venera 拷贝漫画源](https://raw.githubusercontent.com/venera-app/venera-configs/main/copy_manga.js)、[源站搜索](https://www.copy20.com/search?q=%E7%99%BE%E5%90%88%E7%94%9C%E5%BF%83&q_type=)、[百合甜心详情](https://www.copy20.com/comic/baihetianxin)。源站域名可随时间变化。

## 验证

- 40 项 JVM / Robolectric 专项回归已通过，覆盖来源健康、同名分享隔离、链接缓存与参数验证、翻页阈值及方向仲裁。
- 原有 UI 字面量基线检查通过，脚本与基线未变。
- Android 35 x86_64：手机 1080×1920 / 420dpi 24 次、平板横屏 1920×1200 / 160dpi 11 次执行通过；10 个交互用例在两种配置重复执行，包含实际系统链接解析、原文件授权与仿真翻页。合计 40 JVM + 35 设备执行 = 75 次专项验证。正式 arm64 APK 签名与 1.2.6 一致，ZIP CRC、16KB 对齐和构建输入指纹通过；包大小 24,083,676 B，SHA256 `eee91244017acc75de7bcde623cb6cd5f5b0850f264b7ab1cba85581985c7531`。
- 未连接用户真实手机，未声称在微信 / QQ 中完成实际接收。
- 应用详情链接冷启动和 SingleTop 新 Intent 均进入指定标题的详情页；使用已启用来源的合成作品 ID 验证导航，不把它算作真实作品在线阅读成功。未启用来源按设计提示启用后再打开。
