# Ciallo Reader 1.5.6 · 安全签名迁移与动效稳定性

版本 **1.5.6 / 248**，Android 7.0+，ARM64。

## 安装前先备份

**本次完全退休已暴露的旧发布密钥，不能直接覆盖旧签名版本。包名保持不变，但 Android 同时校验签名。**

1. 在旧版「设置 → 设备互传与备份」选择需要迁移的内容，点击「保存本地备份」，保存到下载目录等应用目录外的位置。
2. 确认备份文件已保存且可读取。受保护分类默认不包含在导出中，如需迁移，请先解锁并加入所需内容。书源登录凭据、API 密钥及本机隐私 PIN 不随备份迁移。
3. 备份确认后，卸载旧版，再安装本 Release 的 APK。卸载会删除旧应用的私有数据，请勿先卸载再找备份。
4. 在新版「设备互传与备份 → 打开已有备份或分享文件」导入，核对书籍、阅读进度和所选设置；按需重新登录书源或配置凭据。

这次迁移只需处理一次；之后使用同一新固定密钥的版本按正常更新流程覆盖升级。旧版内置更新器拒绝新签名属于正常安全校验，不要关闭系统防护来强行安装。

## 安全修复

- 旧发布证书对应的私钥条目曾进入公开 Git 历史。本版使用独立的新固定密钥，不携带旧签名历史；新私钥和密码保存在源码仓库外。
- JSON / JavaScript 书源始终验证服务器证书及主机名，旧 `insecureTls` 配置不能关闭校验。阻止 Cookie、Authorization 经 HTTP 或 HTTPS 降级跳转发送。
- 更新下载继续验证官方发布地址、包名、版本、大小、可用的 SHA-256 和完整当前签名集合。保留用户确认后的系统安装流程。
- 成人源及其默认启用方式保留，未更换应用包名。

签名迁移的原因、构建门禁及证书指纹见 [签名说明](app-signing.md)。

## 动效与 Z Fold 修改合并

本版包含今天动效会话提交的 `adc0d923`：减少阴影、光尾、滑条和倾斜动画的重复计算；修复长章在折叠、旋转和窗口变化时的换行、分页锚点问题；改善漫画区域解码的清晰度缓存、并发共享及资源释放。

保留现有视觉和画质分档：「高／极致」启用现有增强动效，「均衡／流畅／极简」使用普通过渡。原动效提交的 145 项 JVM、19 项 Android 回归记录见 [验证报告](performance-stability-2026-10-26.md)。未在三星实体折叠屏上测试，不声称整机占用降至原来的 10–20%。

## 安全检测范围

腾讯官方手机管家 16.1.44 的对照中，原始 1.5.5 以及保留旧签名历史的实验包仍列为 Ciallo Reader「风险软件」；完全退休旧签名的候选包未再列出该风险，重新安装原始包的阳性对照也再次复现。最终构建验收记录见 [安全检测记录](security-remediation-2026-10-26.md)及 Release 验证附件。

最终发布 APK 也完成两次独立检测，均未列出该风险，其间原包对照仍复现。53 项 TLS、更新、备份、成人源默认值和动效分档回归全部通过；最终包启动及主页冷启动检查通过。

测试使用空白 Android 模拟器，没有申请厂商复核、加入信任区或关闭安全防护。**未在 HarmonyOS 3.0 真机上验证，不能保证所有厂商、所有病毒库版本的分类结果一致。**
