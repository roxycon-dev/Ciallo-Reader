# Ciallo Reader 1.6.2 · 2026-11-12

版本 **1.6.2 / 262**。

3D 书架与打开动画这一轮重做了根因：书的打开在过去跨了两个渲染器（书架画布转正 → 覆盖层放大贴图），
中间必然有速度断点；现在整段动画只有一个渲染器、一条时间轴。同时修掉了退出阅读器后某本书变成
黑封面的问题，并大幅补齐中英文切换。

## 3D 书架

- **打开 / 归位动画现在是"一段"**：整本书的绘制抽成 `ShelfVolumeArtist`（纯 `android.graphics`），
  书架和根覆盖层共用同一个渲染器与同一条 `ShelfOpenTimeline.poseAt(p)`。`p = 0` 与书架静止帧逐像素相同，
  `p = .78` 封面铺满全屏，之后才淡出交给阅读器；归位是同一条路径的反向，末帧与静止帧逐参数一致。
- **层级**：被拿起的书画在所有邻书之上（它已经被拿出手了），不再夹在左右邻书之间。
- **书脊不再显示书名**：按需求去掉书脊竖排文字，只保留编号、堵头布与柱面明暗。


## 排列书架

- **书本转角还原为 14dp**（与 1.5.x 观感一致），不再跟随「设置 → 自定义卡片参数 → 卡片圆角」滑条：
  那个滑条一调大，排列书架上的书就会显得过于圆润。飞行动画的起点/落点也用同一个 14dp，
  首帧与卡片仍然严丝合缝。动画本身未改动。
## 修复

- **退出阅读器后某本书变黑封面**：封面预热窗口原本是死板的 `当前书 ± 5`，而实际绘制的是
  `焦点 ± (edgeSlots + 2)` 个槽位（411dp 屏上 18 个，12 本书会全部上屏）。窗口外的书拿不到贴图，
  只能填深蓝灰兜底色 —— 看起来就是黑封面。现在预热窗口按实际绘制的槽位取，兜底色全部改为纸色系。
- 封面光栅化分批（每轮 6 本）并用 `coverGeneration` 触发重绘，切书不掉帧、也不会停在"有书没封面"的中间态。

## 中英文切换

- 修掉一个只在英文模式出现的真 bug：`serialLabel()` 把 `t("连载")` 写进 `when` 条件，英文模式下它是
  "Ongoing"，而书源返回中文「连载」→ 所有作品状态都掉成「状态未知」。现在条件里同时列出中文原文。
- 枚举、`data class`、状态写入层统一改成**读取时翻译**（构造期翻译会把语言永久冻住），覆盖漫画设置、
  缓存清单、引导页、发现页维度、翻译失败原因、翻页方式、触控动作等。
- `tr()` 调用点 1300+、词表 2900+ 条、**缺失 key 0**；工作说明、帮助问答、错误诊断、Toast 全部入表。
- 数据键不参与翻译：分类名、书源 id、解析器生成的章节标题、发布记录正文保持原文。

## 验证

- `:app:testDebugUnitTest`：607 项，5 项既有失败（`AppDatabaseMigrationTest`×2 / `RealEpubPipelineTest` /
  `Round7DataTest` / `DiscoverUiTest`），与基线一致。
- `ShelfSeamTest`（纯 JVM 像素级）：飞行第 0 帧与书架静止帧 **mean = 0 / max = 0**；60 帧扫描无局部尖峰；
  `p = .78` 时封面完整覆盖视口。
- 单测 JVM 的偶发崩溃（JBR 21 的 C2 在 `SQLiteStatement.executeInsert` 上 ACCESS_VIOLATION）已用
  `-XX:CompileCommand=exclude` 绕开。
