# 漫画画质增强重构 · 2026-10-08

用户案例：禁漫天堂搜索 `1444347`，开启超分辨率后放大一直加载。修复覆盖统一漫画阅读器，不按源名或作品 ID 写特殊分支。四档增强、普通锐化及组合滤镜的内存管理一起调整。

## 加载问题

卷页控制器另有 64 MiB / 8 条的小缓存。相邻增强大图入队可淘汰当前页，但 GL 中的纹理仍显示；旧放大层无限轮询已丢失的位图，既不重新加载，也没有失败出口。这是与来源无关的缓存生命周期错误。

现在当前跨的精确缓存键优先保留，放大层直接复用 `ComicPageLoader`、`SinglePageContent` / `DoubleSpreadContent`。缓存未命中会重新加载，失败显示重试；双页分别绘制完整增强位图，移除丢细节的屏幕尺寸快照。所有可见加载有 90 秒截止时间，自己的超时转成可重试异常，外部取消继续传播；超时释放前台优先权。网络与本地图片均在重处理前提供可读预览。

增强失败保留裁边、拆页和旋转，并显式附带错误供 UI 重试；失败原图不冒充增强结果写入缓存。指纹增加 `enhance-v2`，旧增强磁盘结果不再命中。

## 四档与普通锐化

| 档位 | 新处理 | 主要用途 |
| --- | --- | --- |
| 锐化增强 | 噪声门控、亮度细节增益、十字邻域范围钳制、RGB 共同增量 | 软化的文字和细线，保持纸底及色差 |
| Anime4K 轻量 | 保边预降噪 → 原尺寸分块 Restore CNN → 细节恢复 | 清理压缩噪声与线条修复 |
| 超分 完整 | 预算允许时原尺寸分块 2× CNN；其它尺寸 Restore + EASU → 细节恢复 | 低清小字、线稿；大图保留原始信息 |
| 超分辨率 | AMD FSR1 EASU 12 tap 边缘自适应重建 → 去振铃 → 细节恢复 | 斜线、边缘锯齿与放大阅读 |
| 普通锐化滑条 | 共用保色抑噪锐化核 | 与各档、色调滤镜组合；保留增强分辨率 |

放大统一采用等比缩放，最高 2×、长边 3200、目标 6M 像素；已有大图不缩小，小于 15% 的可用放大收益省略。预算约束输出及工作块，不先缩小整页。普通锐化移除旧的 2M 像素缩图路径。

CNN 核修复了多个并行 worker 共享 `FloatArray(4)` 采样缓冲的竞争。256 像素工作块 + 8 像素 halo 覆盖感受野，相邻块只写各自核心区域。Restore 残差去除直流分量，采用边缘门控及共同亮度增量；Upscale 残差同样门控和限幅，避免纸底变色、平坦区棋盘纹与通道饱和造成色差改变。只回收本次处理产生的中间位图，输入、缓存和显示中的位图保留。

已有 `onnxruntime-android` 依赖现在同时服务 OCR 和增强。两份内置图分别 5,560 / 5,550 字节，无模型下载；CPU 会话 2 条内部线程，禁用无界 arena / memory pattern。JNI 或初始化失败自动使用修正后的 Kotlin 求值器，避免设备兼容性影响阅读。`tools/generate-comic-cnn-models.py` 可由仓库固定权重重建模型，核对列主序矩阵、正负激活、边界 padding 和残差输出。

通用 Lanczos 同时修复半像素对齐、边界权重和降采样抗混叠；预计算一维 taps，避免逐像素重复计算正弦。

## 算法依据与取舍

EASU 移植自 [AMD FSR1 官方实现](https://github.com/GPUOpen-Effects/FidelityFX-FSR/blob/master/ffx-fsr/ffx_fsr1.h)，完整 MIT 许可随 APK 打包。收尾锐化是项目自己的保色抑噪内核，不称为官方 RCAS。

CNN 使用 [Anime4K 官方固定权重](https://github.com/bloc97/Anime4K)，保留 MIT 许可。也调研了 [Real-CUGAN 官方实现](https://github.com/nihui/realcugan-ncnn-vulkan)：其桌面 Vulkan 推理与模型质量有价值，但直接引入不能证明 Android 7、不同 GPU、长图及低内存设备有一致体验。本轮使用现有 CPU 运行时和确定性回退。重建真实缺失细节与文字准确性仍受原始输入信息限制，单一合成样本不代表市场横向排名。

## 验证与交付

280 / 280 项漫画 JVM / Robolectric 测试通过（34 个套件，无跳过）；Android 设备测试 Kotlin 编译通过，但没有执行设备测试。UI gate 通过；指南覆盖检查无遗漏，反向检查只有已显式删除的 2 个历史文件。本轮按用户要求不运行模拟器；设备测试源码仅作可选回归入口，不计设备验证通过。`1444347` 的实际源站内容未在 Android 设备运行，根因与修复由缓存压力、真实加载状态和图像处理测试证明。

质量测试使用清晰合成线稿作为参考，降采样后对比双线性与增强的恢复误差，另测纸底、噪声、颜色、透明度、振铃、像素中心、块接缝、取消、位图所有权和加载重试。旧测试要求整页及档间平均色差达到下限，会鼓励变色和噪声，替换为更接近参考图的恢复误差断言；锐度与耗时回归阈值保留。

本地预览 APK 维持 1.2.7 / 208，不修改 GitHub 发布或历史附件。


最终量化结果：斜线 / 文字 2× 恢复样本，双线性 PSNR **24.08 dB**，EASU + 保色细节恢复 **30.25 dB**。另一个软化整页的原始基线 MSE 为 453.17，显示回原尺寸后四档结果：

| 档位 | MSE（越低越好） | 相对基线误差下降 |
| --- | --- | --- |
| CAS | 425.41 | 6.13% |
| ANIME4K | 443.47 | 2.14% |
| WAIFU2X | 433.42 | 4.36% |
| SUPER_RES | 436.54 | 3.67% |

这些是两种特定合成退化的指标，不能外推成所有漫画同等提升。证据图片、测试 XML、模型数值核对与日志位于 `artifacts/enhancement-2026-10-08/`。
