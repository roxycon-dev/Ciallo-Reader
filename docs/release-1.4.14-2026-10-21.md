# Ciallo Reader 1.4.14 · 稳定性修复

本版针对 1.4.13 快速滑动、连续点击下的卡片消失、文字错位和毛玻璃渲染异常反馈。复杂抽纸已统一简化，不继续追求按钮与窗口的柔性纹理融合。

## 具体变化

- 所有原抽纸入口仍使用统一封装，改为轻量弹簧缩放、短位移和透明度过渡。开合可以中断反向；关闭仍更快，原有窗口销毁与后续动作顺序保留。
- 删除动画的额外 HardwareRenderer / ImageReader、GPU 回读、纹理缓存、按钮截图与来源隐藏。正常卡片始终由自己的 Compose 节点绘制，不借给另一个渲染器，不再等待捕获完成。
- 动画只更新常规图层属性，不逐帧测量或重排文字；停稳后没有动画帧循环。卡帧不会触发大量补算。
- 玻璃卡在滚动超过触摸阈值时立即结束触点追踪，避免继续跟随滚动的手指改变文字视差。
- 保留毛玻璃组件与主题、手册 / 缓存的单顶部栏、滑条手势修复、触控分区、原生自由卷页和已合入书源修复。

## 验证

仅运行此次故障相关检查，不重跑无关全量套件。22 项相关 JVM 用例与 3 项真实 HWUI 设备专项通过：

- 极致画质玻璃列表 12 次快速甩动、72 次连点，停稳卡片与操作前逐像素相同；6 次窗口开合，后续动作各执行一次。
- 开合目标 24 次反转后能重新打开、停稳和完整关闭；真实手册开场关闭后重开，手册 / 缓存各一处顶部栏与关闭按钮。
- 设备日志筛选未见 AndroidRuntime / HWUI / OpenGLRenderer 错误；UI gate 保持原基线并通过，工程说明覆盖 722 个源码文件，遗漏 0。

记录见 [专项结果](../artifacts/paper-1.4.14/targeted-results.json)。验证设备为启用宿主 GPU 的 Android 模拟器；没有用其结果承诺所有真机 GPU 的帧率。
