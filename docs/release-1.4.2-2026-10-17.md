# Ciallo Reader 1.4.2 · 2026-10-17

顶部上移并压缩留白，增加内容可视区域；优化发现榜单与状态分类联动，消除完结榜下的连载选项及新作下的重复状态层。

- 五个主页面去掉主容器重复叠加的状态栏留白；共用顶栏缩小上下内外边距，保留系统状态栏安全区、完整标题和英文副标题。
- 发现筛选卡缩小行间距并保留至少 48dp 触摸区域。普通更新、热门与飙升的状态筛选改为独立「状态」行，避免误认为排序的三级分类。
- 「新作」按原站新上架顺序，可能包含仍在连载的作品；去掉重复状态筛选，并在界面解释排序含义。
- 「完结」榜与原站完结入口仅保留已确认完结的可读版本，隐藏全部 / 连载 / 停更 / 未知等冲突筛选；未知状态不视为完结。
- 修复原站「未完结 / uncompleted / unfinished」名称包含完成关键词而被误判为完结的问题；目录能力、入口匹配和状态补全使用一致的否定词规则。
- 普通状态筛选继续作用于当前栏目数据，保留原榜单顺序、分页会话及缓存；切换新作或完结时上层规则覆盖旧状态。
- 版本升级至 1.4.2 / 225，更新中英文 README 与应用内更新目录。

验证结果：50 项 JVM / Robolectric / Compose 回归全部通过（界面 22、ViewModel 23、状态作用域 5）；另通过离线 JS 语义协议验证，涵盖否定标签、完结父栏目与混合分区、原站状态选项及游标恢复。检查了浅色、新作以及深色 130% 字体截图；截图使用测试书源。本轮未运行模拟器或真机安装，也未重新验证第三方书源的实时可用性。
