# Ciallo Reader 1.6.1

版本 **1.6.1**（版本码 **260**），2026-11-10。

## 平板排版与自适应布局

- **平板设置按组呈现**：设置项的标题与对应内容归入同一组，宽屏分栏和窄窗单列使用同一分组顺序。
- **书库、发现按可用宽度组织结果**：结果区根据剩余宽度调整列数与信息密度，不沿用上一窗口的固定列宽；搜索、筛选与结果仍各自成区。
- **书架移除重复的阅读空间**：减少同一阅读信息在多处重复出现，保留继续阅读入口和书籍网格。
- **旋转与窗口变化后重新布局**：旋转、分屏和窗口尺寸变化后按新宽度重新判定栏数与分组；布局切换不缩放内容，避免旧宽度下的测量结果被拉伸。

## 更新检测

- **启动静默检查**：启动后静默查询是否有更新的正式版本，只有确实存在新版本时才提示；检查失败不打断阅读。
- **设置中手动检查**：可在设置中主动检查并看到结果；失败时保留可读原因，可稍后重试或打开 GitHub 发布页。
- **官方 GitHub 与显式镜像**：版本信息来自 GitHub 官方发布；下载默认使用官方地址，也可在更新窗口显式选择 HTTPS 镜像。镜像只承载官方安装包字节，不提供版本元数据。
- **校验流程不变**：安装包继续按官方签名校验。镜像下载要求官方发布提供 SHA-256，并同时匹配官方安装包地址与该 SHA-256；没有官方 SHA-256 时不提供镜像入口，浏览器下载始终回到官方地址。

## 设计指南

1. **标题与内容同组**：平板设置以组为单位排版，宽窄切换时保持标题和对应内容一致。
2. **结果跟随宽度**：书库与发现按可用宽度决定列数和信息密度，不把某一屏宽下的列数写死。
3. **阅读入口唯一**：书架只保留一处继续阅读空间，避免重复卡片挤占书籍区域。
4. **旋转只重排**：旋转和窗口变化只重新计算布局，不缩放内容，不把旧窗口的测量结果带入新窗口。
5. **更新路径可核对**：官方发布为默认来源；镜像必须由用户显式选择、使用 HTTPS、提供官方 SHA-256，并继续通过官方签名校验。

组件接线与动效规则见[界面动效与交互规范](UI_MOTION_INTERACTION_GUIDE.md)。

## 安装与校验

- Android 7.0（API 24）及以上，arm64-v8a；安装包文件名 `Ciallo-Reader-v1.6.1.apk`。
- 已安装旧版的用户升级前建议先在「设置 → 设备互传与备份」导出备份；覆盖安装由系统按签名校验处理。
- 下载页：[GitHub Release v1.6.1](https://github.com/roxycon-dev/Ciallo-Reader/releases/tag/v1.6.1)。校验文件随 Release 提供，文件名为 `SHA256SUMS.txt`。
- 更新窗口中的镜像入口不改变校验流程：安装前仍核对官方 SHA-256 与官方签名。
