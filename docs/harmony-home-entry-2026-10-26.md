# Issue #3：进入主页时闪退的兼容修正

## 反馈与结论边界

[Issue #3](https://github.com/roxycon-dev/Ciallo-Reader/issues/3) 更新后的描述为：1.5.5 风险名称 `a.gray.BulimiaTGen.h`，HarmonyOS 3.0，点击“开启阅读”或“跳过”后闪退，再次打开也闪退。两条操作都会保存 `has_seen_onboarding=true` 并进入 `home`；以后启动跳过引导，直接加载同一主页。这能解释触发路径，但不是崩溃堆栈，不能据此确认唯一根因。

没有反馈机型号、系统完整构建号、系统日志或 HarmonyOS 3.0 真机。本次以已发布 1.5.6 的安全修复提交 `892869d9` 为基础，制作本地 **1.5.7 / 249 验证包**，没有发布 GitHub Release 或追加 Issue 回复。不能把下面的兼容改动和模拟器结果表述为已在原设备复现并根治。

## 修改

- 实时玻璃能力同时检查画质和系统是否支持 RenderEffect。此前 Android 12 以下虽然在最终绘制处使用了替代样式，根背景、主页底栏及弹层仍会挂接没有用途的背景采样图层。现在这些系统直接使用既有磨砂底色，不进行相关采样；支持的系统继续保留高画质效果。没有按厂商名称强制关闭所有效果。
- 在主页第一次组合前启用 20 秒的渲染故障恢复窗口，离开主页或稳定运行后解除。窗口内实际发生 Java/Kotlin 界面渲染异常时，在原有系统崩溃处理结束进程前，同步保存极简画质，让下次启动避开高级渲染路径。仍保留原始本地崩溃诊断和 Android 默认异常处理，不在已崩溃的界面上继续运行。
- 恢复只改变画质并在下次进入主页时提示，可在设置中自行调整；不清除数据库、阅读进度、引导状态、登录信息或书源。正常重启、无关后台错误、窗口外错误和内存耗尽不触发该恢复。
- 成人源、脚本及默认开启逻辑保留；1.5.6 的 TLS 和新固定签名修复保留。此包没有进行新的杀毒检测，不宣称风险分类已得到厂商复核。
- 设置 → 关于的“导出启动诊断”改成带图标的完整按钮，移除下面的小字。按钮打开系统保存文件窗口，日志生成与写入放在后台；取消、保存失败均可重新操作。
- 诊断包包含设备与系统构建、屏幕/字体/方向、应用版本、安装包 SHA-256、崩溃时堆/系统内存和存储、异常消息与完整异常链（含 suppressed）、线程状态及堆栈、页面模板、引导按钮操作、启动任务的起止与结果。保留最近 256 个阶段事件、上次进程事件和最近 8 份异常历史，最后一次崩溃独立保存，不被普通启动错误覆盖。异常链、线程与文件均有容量上限，凭据/URL/私人路径进行脱敏，不导出书库或账号设置。
- Android 11+ 导出时查询本应用的系统退出原因、退出状态、内存统计及系统可提供的 ANR/native trace。旧系统明确标识此能力不可用；不下载额外组件，不申请跨应用日志权限，不自动上传。安装包哈希用于找到对应构建的 mapping.txt，不能用其他包的映射文件替代。

原生崩溃、系统直接杀进程或系统查杀拦截可能没有 Java 异常，恢复机制不能保证覆盖这些情况；仍需要反馈设备的日志定位。

## 验证

只使用本机已有 API 30 AVD `ciallo_security_api30`，没有下载或创建模拟器/系统镜像。这是 Android 11 模拟器，不是 HarmonyOS 真机。

- 改动前：同一模拟器上的正式 1.5.6 可进入空书架；原始主页、卡片和底栏在 Robolectric API 28 / 30 上的 4 项组合检查通过。因此不声称已重现反馈机的故障。
- 本地单元回归 **28 项通过**：覆盖 API 28 / 30 主页、卡片、底栏与采样能力；现代系统保持实时玻璃；实际渲染错误后的持久化恢复、无关错误排除、恢复窗口与代际清理；既有启动诊断、画质动效与成人源默认设置；深层堆栈/异常链/脱敏/历史轮转/有界轨迹，以及点击保存、取消和实际文件内容导出。
- Android 设备回归 **3 项通过**：真实 MainActivity 上“跳过”和完成全部四页引导均确认空书架可见，关闭 Activity 后重新启动仍能进入主页；设置页按钮可见、可点击且旧小字已移除，已保存并检查截图。测试只修改独立调试包的相关设置，测试结束恢复原值。
- 在同一 API 30 模拟器手动从设置点击导出，完成系统文件选择与保存，实际取得 40,549 字节的日志；包含上次进程与本次启动任务、页面轨迹、设备环境、线程及系统退出历史，APK 摘要与对应调试包核对。系统自身的历史异常没有冒充为应用异常。
- 为正式包的恢复分类保留渲染栈类名（仍可裁剪和优化），避免 R8 把识别用的类名改掉。其他正式包堆栈仍按同次构建的 mapping.txt 还原。

聚焦回归入口为 `tools/home-entry-tests.gradle` 和 `tools/home-entry-device.gradle`，设备类为 `com.example.ui.HomeEntryDeviceTest`。本地构建日志、测试结果、最终 APK、mapping 和摘要保存在 `artifacts/home-entry-1.5.7/`，不进入 Git。

## 安装与后续确认

验证包使用与 1.5.6 相同的新固定发布证书，可覆盖该版本。旧签名 1.5.5 的迁移仍应遵循 [签名说明](app-signing.md)，先导出备份再处理安装，不能通过清空用户数据来验证修复。

反馈设备应优先确认两个引导出口及重新启动，再检查正常阅读。若仍闪退，保留完整系统提示、时间和机型；能进入应用时导出启动诊断，不能进入或记录为空时需要设备侧系统日志。报毒与闪退仍分别验证，不从其中一种现象推断另一种现象的原因。
