版本 **1.5.4 / 246**。

**升级提示：1.5.3 对照包可直接覆盖升级；1.5.2 及更早旧包名需先导出备份，再安装新版并导入，不能原位覆盖。**

## 动效按画质分档

| 画质 | 弹层与控件 |
| --- | --- |
| 高、极致 | 保留现有抽纸变形、液态按钮、水滴分段选择、液态滑条和挤压开关；极致专有装饰继续按原规则启用 |
| 均衡、流畅 | 普通弹簧缩放与淡入淡出、基础按钮和标准开关/滑条/分段选择，不创建液态控件渲染器 |
| 极简 | 基础控件与原有减少动态效果策略，开关继续使用简化勾选框 |

切换画质不重置滑条数值、范围或选项；已打开的抽纸窗口降档后，关闭时也使用普通过渡。Android 版本不支持所需图形 API 时仍沿用原有兼容路径。阅读器内用户选择的翻页类型不受此分档修改。

## 启动和既有功能

- JS 书源登录状态直接读取本地记录，启动检查不再为此加载原生 JS 引擎。
- 可选启动任务、临时分享清理、系统朗读引擎初始化与 Wi-Fi Direct 权限变化增加异常保护。
- 设置 → 关于新增本地启动诊断导出，不自动上传账号、书籍或阅读记录。
- 成人源保持默认启用，安装权限、安装器与原更新安装流程保留。

## 包名与升级

沿用用户已验证未再报毒的 1.5.3 对照包身份 **`com.roxycon.ciallo.reader.probe`** 和原固定签名，显示名称恢复为 **Ciallo Reader**。已安装该对照包可直接覆盖升级，原数据留在同一应用中。

旧包名 **`com.aistudio.novelreader.kxmpzq`** 的用户需要先使用「设置 → 设备互传与备份」导出，再安装本版并导入。旧版与新版独立安装，不会自动共享书库、登录或阅读记录；请确认迁移成功后再处理旧版。

用户反馈仅确认此前那份对照包在其设备上未再报毒，不代表本版已通过所有厂商、机型或病毒库的安全检测。
