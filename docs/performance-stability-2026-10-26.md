# 第二轮算法、稳定性与窗口适配验证

本轮基于 `10d1f206`（1.5.5 / 247）。保留现有画质分档、布局、材质、动画参数、触觉与公开组件接口。交付为本地验证 APK；正式发布链接和版本号没有替换。

## 修复与优化

- 水平阴影模糊按边缘区间更新滑窗，保持整数累加及浮点舍入；468 组尺寸、半径和尾缓冲逐位对照。
- MAX 发光复用固定圆角轮廓、签名、PathMeasure 与 Stroke；同一既有量化半径桶复用解析结果。动态光尾继续实时计算。
- 滑条复用尺寸、密度与提示文字测量，隐藏时停止帧请求，重新显示或挂载后恢复。
- MAX 滚动倾斜收敛后挂起帧订阅，滚动输入唤醒下一帧；保留指数积分和阈值，10,000 步轨迹逐位一致。
- 渐变、边框轮廓和描边按绘制缓存复用，窗口、密度和颜色变化准确失效。旧 Android 磨砂回退保留原像素。
- 长章分块保留换行、CRLF、代理对与图片 token；行数据使用原文偏移和基础数组，扫描及页测量之间可取消。图片边界守护采用线性扫描，协议保持兼容。
- 同章重分页期间保留旧完整页面，新尺寸全部分页就绪后切换，防止深阅读位置暂时跳到前半章末尾。排版缓存补齐布局样式、密度、字体缩放与字体环境；颜色变化复用布局，字体环境弱引用最多 64 条。
- 漫画区域缓存区分目标分辨率并冻结裁剪坐标；并发同区域共享结果。清理和退出时延迟释放正在借用的 native decoder，拒绝旧代次回填，释放未发布结果及私有 EXIF 中间位图。
- 漫画卷页补齐密度、自定义缩放和双页偏移的几何失效，复用管线指纹与同位图的玻璃包装；私有背纹理中间位图同步绘制后释放，保留原重采样与 RGB565 量化。
- 预烘焙玻璃在源变化时重新调度；取消快照不再污染能力探针，过期窗口快照不发布。

缓存保留原有预算：分页 8 MiB、区域图 32 MiB（极简模式 4 MiB）、decoder 最多 4 个（极简 1 个）；新增几何缓存随绘制节点释放，没有按动画时间增长的缓存。

## 已完成验证

- **145 项 JVM / Native 对照与回归全部通过**，0 失败、错误、跳过；现有 UI 门禁通过，基线未修改。
- 原有按钮 32 个按压/释放帧、开关 15 帧、滑条 576 帧；新增 MAX 呼吸、环绕光尾、窗口缩扩和真实主按钮按压释放 **24 帧，0 像素差异**。装饰及旧 Android 回退另有 12 组尺寸、颜色对照。
- 冻结 1.5.5 分页实现，16 组固定种子短章逐页相同。长章完整拼接恢复旧分块丢失的换行；插图、字号、行距与标题高度的既有 7 项测量回归通过。
- **19 项 Android 模拟器回归通过**：真实窗口中的滑条隐藏/恢复、同尺寸重新挂载、玻璃源替换、原生区域采样及并发共享、动态背景、弹层反向与重复开关、文字和触控区域、64 帧 GPU 滑条图层对照。
- 284,892 字符的长章在正文偏移 227,913 处连续执行 6 次窗口变化和 320 / 480 / 420 dpi 切换，完整页就绪后出现的残缺发布为 **0**，阅读锚点与控件状态保留。

区域加载器的 JVM 并发测试显式使用可控 decoder 替身，因为 Robolectric 4.14.1 缺少 API31 新方法且忽略采样率。原生 codec 的分辨率和共享另由上述 Android 测试实际验证。窗口与密度模拟使用现有 Pixel AVD 的 `-read-only` 临时实例，GPU 为 NVIDIA RTX 4060 Laptop / host GLES；不冒充三星实体机或 One UI 铰链测试。

## 测量与边界

分页局部测量为固定相同正文、十组成对交替、每样本 60 次布局。Windows JVM 托管分配的成对中位数减少 **6.83%**；CPU 差异置信区间包含 0，未证实 CPU 加速。原始文件 `pagination-pairs.json`。

水平阴影 Windows JVM 局部测量为十组成对交替、每样本约 1.6 亿像素，新 / 旧 CPU 中位数 **78.6–88.5%**。这是单个内核的宿主数据，不能外推整款应用、GPU、功耗或三星帧率。

发布配置的整页 MAX 交替采样完成 8 个完整对、保存 17 个样本后，读取第 9 对结果时 ADB 超时；期间发现宿主内存压力和帧时间明显漂移。原始样本保留供排查，该批数据不用于验收 CPU/GPU 提升或流畅度百分比；功能与像素测试的通过不依赖这些帧时间。扩展后的 Android 水平内核 probe 已编入隔离 R8 包，本轮未运行，不将宿主测量冒充 Android 数据。

**整款软件 CPU/GPU 降到原来 10–20% 的目标未得到证明。** 实时光尾模糊、玻璃折射、滑条软件位图重绘和必要文本测量仍有成本；单次原生 Paragraph 调用只能在调用前后取消。本轮按用户要求收尾，不声称达到理论最优。
