# 多语言搜索 v4：在线恢复、卡片与详情交互

本轮基于已合并上游的 `74983bf0`，版本仍为 1.2.1 / 202。本地既有修改保留。

## 行为

- 输入中文先发送原词，再发布本地映射。在线查词与书源搜索分开运行，可靠名称到达即展示并继续发送，不添加书源语法，不筛掉书源返回的结果。
- 查词读取 Android 系统 HTTP 代理；连接 / 读取 / 请求总超时为 4 / 6 / 8 秒，流式补词窗口 20 秒。后台词典维护独立运行。
- Bangumi 单个资源的 HTTP、网络或 JSON 失败不再抑制同域其他资源。429 / 503 保留 Retry-After 限流；角色 / 人物搜索含 infobox 时直接使用，避免重复拉取详情。
- 搜索用词采用书源管理页同款 `GlassKitCard`，保留默认形状与中性样式；它是结果列表首项，聚合全宽，随结果滚走。
- 展开显示实际名称、来源、提交书源数和各资料提供者状态。失败显示超时、HTTP 等具体原因；“重新查词”跳过普通缓存重试等待，仍遵守全局无痕与服务限流。新的提供者结果覆盖旧失败状态。
- 缓存兼容旧格式，保存可靠名称和提供者状态 / 原因；离线可再次命中，在线结果不冒充书源结果。
- Tab 横杠在等宽槽位间弹簧移动，绘制读取动画值；收缩不改变横向宽度，支持 RTL。实时玻璃背景不再因滚动切换成实心底。
- 详情标题、作者、编号和标签点按搜索；长按选中文字并使用原生复制。自定义复制 / 搜索弹窗已移除。简介与元数据也可选字。

## 实证

本机直接请求 Bangumi 超时；经已配置系统代理的请求返回成功。生产查词客户端的真实 API 探针取得：

| 输入 | 真实返回的部分名称 |
| --- | --- |
| 雪之下雪乃 | 雪ノ下雪乃、Yukino Yukinoshita、ゆきのした ゆきの |
| 渡航 | わたりわたる、Watari Wataru |

原始探针摘要在 `artifacts/multilingual-search-v4/live-api-results.json`。探针为 Robolectric 环境，只提供其缺少的系统代理 getter；生产 HTTP 客户端与公开 API 请求真实执行。该检查不代表手机当前网络可用，也不代表 E-Hentai 账号命中率。

91 项核心回归、11 项 Compose Native 界面 / 手势回归、1 项真实 API 探针；设备测试编译与 Release 构建结果、签名、APK 指纹见交付目录的 `verification.json`。截图为生产组件和列表条目函数的测试容器，非完整手机截图。选字测试仅替代 Robolectric 不支持的 Magnifier popup，选择与复制回调实际执行。

全局 UI 静态门禁仍有既有工作区和上游字面量超限，本轮数量与上一轮一致，未改基线；详情与 Tab 使用既有样式。未修改翻译路径，未发布 GitHub Release，未做真机运行验证。

## 手机验收

1. 开启多语言与在线补词，关闭全局无痕，搜索本地缺少的角色或作者。观察实际外文名称、缓存状态与提交数量；再次搜索应可使用缓存。
2. 若网络失败，展开卡片看具体提供者原因，修复网络后点重新查词。无痕下应显示暂停，不应显示未启用。
3. 滑动结果，搜索用词卡片应滚走；回顶可见。大字体下两项开关说明应完整。
4. 快速切换 Tab，横杠应连续移动；上下滚动后仍对齐，背景不突然变实心。
5. 详情点按标签只搜索一次；长按标题、作者、编号或标签，拖动选字后复制，不应进入搜索或弹出自定义菜单。

资料接口：[Bangumi 官方 API](https://bangumi.github.io/api/)。
