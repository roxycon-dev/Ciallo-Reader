# Ciallo Reader 1.5.16（2026-11-07）

> 版本：**1.5.16 / 258** · 上一版 1.5.15 / 257
> 主题：**EPUB 连续插图显示错误修复（issue #6）+ 小图不再被放大**

## 修复内容

### 1. 极简渲染质量下，连续插图全部显示第一张

- 现象（issue #6）：连续 3 张以上插图时，正文里显示的都是最前面那张；点开大图却是正确的那张；退出大图后，前后几张又都变成刚看过的大图。
- 原因：插图位图状态挂在 Compose 组合槽位上，没有跟着图片路径走。极简质量走 `PageTurnContainer` 的极简分支（只组合当前页、无按页重建），翻页时同一个槽位被换成新的图片路径，位图状态却保留了上一张。
- 修复：新增 `rememberKeyedAsyncState`，值随 key（图片路径）重建；正文插图与全屏查看器都改用它。翻页后正文与大图必定一致。

### 2. EPUB 小图被拉满整栏

- 现象：`<img>` 尺寸很小的分隔符、装饰图（例如 20×20 的 `note.png`）会被拉成整栏宽的一块。
- 原因：`displaySize` 无条件把宽度设为内容宽，只处理"太高"，没有"不超过原图尺寸"的上限。
- 修复：宽度上限取 `min(内容宽, 原图宽 × 屏幕密度)`；分页测量与渲染共用同一口径，不会再出现测出来和画出来不一致。
