# Ciallo Reader 1.4.1 · 2026-10-15

修复禁漫天堂旧线路、连接中断与旧缓存补丁迁移，记住可用线路；移除发现「热议」入口，保持榜单热门/飙升/新作/完结结构；补齐设置内更新目录至 1.4.1。

- 禁漫接入发布方当前动态目录中的四条内置线路，保留在线刷新和上次成功配置；配置请求失败时继续使用缓存，不让后台图片分流请求报错打断浏览。
- 只读 GET 走 OkHttp，JSON API 单次连接 4 秒、读取/整次 6 秒，配合最多五条线路与总换线预算；验证解密数据后记住线路，重启恢复；手动切换仍有效。保留系统 TLS 校验、鉴权拒绝与取消停止、POST 不跨线路重放。
- 修复旧缓存中无缩进 get 方法无法命中后续补丁的问题，兼容 LF/CRLF，重复修补保持幂等；实际运行响应适配器同步保存和恢复可用线路。
- 移除发现热议入口，将旧的热议选择迁移到更新；内部保留旧枚举兼容缓存。榜单依然为热门、飙升、新作、完结，没有混入讨论榜。
- 设置→软件卡片→更新目录补齐 1.3.7、1.3.8、1.3.9、1.3.10、1.3.11、1.4.0、1.4.1。

仅检查本次改动：24 项 JVM/Robolectric 回归（发现、旧选择迁移、缓存补丁与设置更新目录）；6 项禁漫响应契约；断连换线、无效响应、线路记忆/重启、手动选择、授权失败和启动缓存的离线验证。

线上验证：禁漫冷启动目录 180 本→详情→章节 42 张图片→首图 HTTP 200 / 95,604 B（WEBP）；与 App 相同的 OkHttp HTTP/1.1、超时和生产 DNS 配置，实际 API 返回 HTTP 200。未启动模拟器，不把桌面脚本验证说成真机测试。
