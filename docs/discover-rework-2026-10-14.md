# 发现页返工审查 · 1.3.9 / 220

用户已确认本轮截图并授权编译上传新版本。1.3.9 / 220 正式包编译及签名检查通过；安装与发布信息见 [本版验证记录](release-1.3.9-2026-10-14.md)。

## 界面

- 发现与书库调用同一个 `CollapsingTabScreenHeader`，共用状态栏 inset、字体、边距、圆角和全局玻璃配置；滚动后顶栏逐步收起至零占位。只有维度条固定，书源、范围和分类入口随内容滚动。
- 设置按钮打开独立 `AcrylicDialog`，浏览布局在窗口内切换；使用全局 `GlassCard`、`SegmentedPillSelector` 和原始 60×32dp `AppSwitch`。删除默认源、默认维度、成人分类开关、休息提醒以及全局设置末尾追加的发现卡片。成人分类默认可见。
- 分类按题材、情感、设定、受众、形式与来源、成人与偏好浏览；搜索与原站分类单独提供入口。多选在窗口内保存草稿，按应用一次请求，清除可恢复全部。数量、今日更新只表示已经加载的作品。
- 使用当前 `MascotSpriteSheet` 资源。大字号下卡片自然增高，范围与书源行各自占位；长按菜单、追漫、随机阅读保持可用。

## 数据、分类与刷新

- 同一个查询不重复加载；切源/切维度保留独立页码、游标、内容及视口，底栏往返使用 `SaveableStateHolder`。最多 12 个会话 / 8,000 条结果；手动刷新防重入并有 3 秒冷却。
- 每源目录和数据分别有 50 秒超时预算，最多 3 源并发；动态目录通过源内 Mutex 合并同时到来的分类窗口与列表请求，分类加载失败可重试。公网 HTTPS GET 的传输错误允许用另一客户端请求同一地址，不更换认证线路或重放登录 POST。
- 离线缓存使用持久源身份/版本键，跨重启复用；保留真实空统计。解除屏蔽清理该作品的跨源身份组，同时保留其他屏蔽作品所共享的身份。
- 原站实际支持的维度、时间范围决定按钮可用性；没有日期的作品不会被算作今日更新，没有点击数据的热门列表不会冒充点击量。
- 补齐 EH 的 10 个原站内容形式、哔哩 12 个题材、扑飞 212 个动态入口、MangaDex 官方 tag 目录。原站标签做繁简、复合标签和别名映射；语言、年份、IP 与未知分类仍有原站搜索入口，不猜测作者/角色的题材。
- 哔哩分类每页 30 本，改读原站分页链接，移除按 50 本终止的错误假设；提取作者、状态、实际阅读数并拆分复合题材。
- MYCOMIC 负号排序值 `-views`、`-week`、`-month` 保持完整，三个推荐入口身份和参数各不相同。点击型榜单不额外声明另一种统计维度。

## 验证范围

1. 配置路由脚本：书库配置的 19 个 JS 源，55 个推荐入口、1,357 个静态分类，1,412 个入口分派及 6 项边界契约通过；每个推荐入口 ID 唯一。采用固定数据加载器，证明协议路由、游标与参数，不冒充全站在线可用性结果。
2. 针对新增分类的实际联网抽查：哔哩奇幻冒险前两页各 30 本，第二页新增 30 本，均有后续页；扑飞目录 212 类，冒险前两页各 40 本，第二页新增 40 本。没有重复请求其他健康源。
3. JVM/Compose 回归覆盖解析、独立指标、公平去重、分页重试、切栏恢复、离线缓存、动态分类请求合并、屏蔽解除、原站参数及原有书库导航。累计 116 项通过，零失败/错误/跳过；最后分类范围修正另复验 UI 11 项。结果见 `artifacts/discover-rework-2026-10-14/verification.json`。
4. 截图使用实际生产 Compose 界面、390dp×844dp、SDK 35 Native Renderer 与均衡渲染档；数据来自测试书源，封面复用仓库已有测试样例。浅色首页、滚动、源窗口、分类 130%、设置、深色榜单 130%、大图菜单和深色设置 130% 均需目视复验。

截图目录为 `artifacts/discover-rework-2026-10-14/screenshots/`。这些不是手机实拍，也不证明所有 GPU 上的实时模糊效果；没有启动模拟器。

Robolectric SDK 33/34 的 child shader 报错来自测试环境旧版 Native Skia，[上游 #9691](https://github.com/robolectric/robolectric/issues/9691)说明 SDK 35 支持。最终截图与着色器编译用例使用 SDK 35，生产着色器没有为此改写。
