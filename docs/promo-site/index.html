反馈与建议
可以离线阅读吗？

可以。导入的本地文件，以及已经下载完成的小说或漫画章节，都能离线阅读。在线搜索、在线阅读与网络翻译需要连接相应服务。

安装包里包含小说或漫画吗？

安装包不包含作品内容。你可以导入自己的文件，或配置自己选择的第三方书源。第三方内容与来源的可用性、使用条款由相应提供方决定。

漫画翻译如何工作？

OCR 与气泡检测在设备上完成，译文由你选择的在线翻译服务或自定义 API 生成。MangaJaNai 完整版首次使用需下载约 76 MB 模型，之后可离线增强；也可选用轻量处理。

MIT 许可证涵盖所有资源吗？

MIT 仅适用于项目原创源代码。第三方模型、词库、字体等资源遵循各自的许可。 查看第三方许可
