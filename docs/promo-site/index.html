常见问题

支持离线阅读吗？

本地导入文件和已下载作品可离线阅读。在线搜索、部分语音、在线阅读和网络翻译需要连接相应服务。

在哪里选择国内下载镜像？

打开设置中的「关于 → 检查更新」。同一更新面板提供 GitHub 和国内 HTTPS 镜像选项，镜像需要可验证的官方 SHA-256。

需要登录才能使用吗？

本地阅读无需登录。部分第三方源的账号、验证和下载权限按提供方规则处理。

漫画翻译和增强要联网吗？

OCR 和气泡检测在设备上执行。译文由所选在线服务生成。MangaJaNai 完整模型首次下载后可离线使用。
