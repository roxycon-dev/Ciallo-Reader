一个书架，收好不同格式

导入 TXT、EPUB、MOBI、AZW、AZW3、PRC、DOCX、FB2、CBZ、ZIP 或 PDF。收藏、书签和阅读进度集中管理。

按自己的方式阅读

小说可调字号、字体、行距、主题和翻页方式；漫画支持单页、双页、条漫、滚动以及阅读方向设置。

联网搜索在线书源并下载小说或漫画章节，完成后从本地书架继续阅读，无需网络。

下载前，
先了解几件事。

可以离线阅读吗？

可以阅读已导入的本地文件，也可以阅读已下载完成的小说或漫画章节。在线搜索、在线阅读和联网翻译仍需要网络。

安装包里包含小说或漫画吗？

不包含。你可以导入自己的文件，或按自己选择的在线来源搜索。网络内容和来源条款由提供方决定。

漫画翻译如何工作？

OCR 和气泡检测在设备上完成；生成译文时会使用你选择的翻译服务或自定义 API。发送前请了解所选服务的数据和隐私条款。

MIT 许可证是否涵盖所有资源？

MIT 适用于项目原创源代码。第三方模型、词库及其他注明独立许可的资源仍受各自条款约束。查看第三方许可记录。
