# 水滴分段选择条（2026-10-13）

## 范围

按用户本次要求，只替换分段选择条。漫画/小说阅读器、底部导航、书库类别切换和分类标签保持原实现。

- 通用 `SegmentedPillSelector`：软件背景、屏幕方向、渲染画质、定时休息、统计周期、阅读趋势和阅读日历。
- Z-Library/书源登录弹窗：账号密码和 Cookie 方式选择，保留原 48dp 高度、14sp 文字与登录逻辑。
- `ShelfSegmentedTabs` 兼容入口：保留书架标题、收藏心形和数量，使用 36dp 紧凑条。当前 HomeScreen 使用独立区域，这个兼容入口不改变主页结构。

## 实现

参考用户提供的 `睡眠定时.txt` 中的光学和物理代码，移植到 Android 原生 Canvas + AGSL。无需 WebView、GLSurfaceView 或独立渲染线程。

- 玻璃凹槽、分隔线、底部亮边和主题色暖光。
- SDF 水滴、中心放大、7.5% 通道位移色散、双高光、底部焦散、速度/按压阴影。
- 两根边缘弹簧、加速度驱动的倾斜弹簧、三颗惯性小水珠与 smooth-min 融合。
- 点按、水平拖动、速度保留、边界阻尼、方向键/Home/End、RTL、TalkBack 单选语义、减少动态效果和深色主题。
- Android 13+ 且启用装饰效果时使用原生着色器；旧系统、极简/流畅档和不兼容驱动使用原生玻璃胶囊。

## 开销控制

- 轨道和文字纹理仅在尺寸、文字或对应主题参数改变时更新；选项切换不重建纹理。
- 文字只需要覆盖率，缓存使用 ALPHA_8；相比同尺寸 RGBA 字形缓存，字形数据字节数减少 75%。这是格式大小比较，不代表整机内存降幅。
- 物理状态留在原生绘制节点，动画不写 Compose 页面状态；只在松手后提交一次设置回调。
- 动画收敛后不再调度帧；手指保持静止时也可停止帧回调。
- 静止时只缓存选择条本身的硬件绘制层，避免父页面滚动时重复执行折射计算；动画、隐藏和销毁时移除该缓存层。
- 动画按 dp 计算、每次物理子步最多 1/120 秒，支持不同屏幕密度和刷新率。
- 页面暂停、窗口隐藏、控件脱离窗口时取消回调并归位；销毁时释放纹理和着色器引用。

## 验证

测试源：`LiquidSegmentPhysicsTest` 与 `LiquidSegmentSelectorTest`。覆盖不同帧率的收敛、拉伸/小水珠、边界阻尼、静止手指、取消/减少动态效果、真实 Skia 编译着色器、纹理复用、点击和键盘、父页面纵向滚动、旧系统、浅/深色与紧凑宽度。

构建验证阶段的 11 项测试通过。用户随后要求不再编译打包，已停止后续构建；最后补强的自定义值像素断言未重新执行。代码对自定义值使用未选中状态，避免误显示关闭档位。

光学测试使用 SDK 35 的硬件 RecordingCanvas/RenderNode；Robolectric 的 SDK 26–34 使用较早的 Skia，无法验证子着色器 `.eval()`，详见 [Robolectric #9691](https://github.com/robolectric/robolectric/issues/9691)。SDK 28 单独验证降级交互。

本机没有连接 Android 真机。真机驱动显示效果、gfxinfo 帧率与整机内存变化仍需设备验证，不报告未测量的性能百分比。

构建环境的 JBR 本地通信需要短路径：使用本次命令范围内的 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\liquid-tmp`；未修改项目的 Java/Gradle 配置。
