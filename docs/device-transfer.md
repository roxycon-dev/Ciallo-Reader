# 设备互传与便携备份

入口：设置 → 设备互传与备份。双方首次启用后授权附近设备；软件前台广播接收能力，后台仅保持已经开始的任务。

1.4.5 补齐附近连接的主动建组查询、独立监听和角色握手，见 [附近连接修复记录](release-1.4.5-2026-10-18.md)。两端需更新到该版本或更新版本，旧附近任务取消后重新发现设备。

1.4.4 统一为书源管理使用的毛玻璃页面与卡片，并修复 Android 原生 TLS 密钥授权及发现端口／网络路由。两端均需更新；旧任务取消后重新发送。原生 Android 握手、数据收发与界面渲染验证见 [修复记录](release-1.4.4-2026-10-18.md)。

## 使用

- 默认选择全部类别，排除受保护内容；可调整类别，PIN 验证后加入受保护内容。
- 发送方选择设备，双方核对六位校验码并确认。优先局域网，也可使用附近 Wi-Fi Direct；不依赖谷歌服务。
- 默认合并，保留本机设置与同标识书源，阅读进度取最近时间。只有完整数据校验和导入成功后，发送方才显示“对方已导入”。
- 整机迁移需要单独确认。替换书籍也替换关联标注和历史；迁移前保存最近一份回退快照，完成后重新打开应用。
- 无法直连时，分享 `.ciallo` 数据包，或保存本地备份；另一台设备打开文件后使用同一套检查和导入逻辑。v1 ZIP 仍能读取。
- 仅发送设置、标注或历史时，书籍只携带匹配所需的身份与章节元数据，不包含正文。接收机没有匹配书籍时跳过关联数据并说明原因。

## 实现

`transfer/` 分为发现、TLS、分块协议、任务管理、前台服务、便携归档、导入协调和 Compose 页面。协议 v1，数据包 v2；Room v13 增加稳定身份、导入收据和章节查找索引。

TLS 使用 Android Keystore 设备证书，双方确认绑定证书与随机数的校验码后才发送用户数据。分块为 1MiB，每块 SHA-256 和落盘后确认；完整包再次校验。续传绑定原证书与随机会话令牌，缓存保留 24 小时，在后续启动时清理。

数据库、偏好设置、神回 DataStore 和书源定义通过私有 undo journal 协调；Room 首次打开会恢复未完成的提交。导入前验证格式、字段、资源路径、关联、条目预算和校验值。登录、Cookie、密钥、隐私 PIN、模型与下载队列不进入数据包；不明确的认证配置会被跳过并提示。

已知阅读会话取去重后的并集；无法确认来源的历史日汇总仅合并剩余时长的较大值，避免往返互传重复累计。数据包重复导入由收据短路；不同数据包按内容身份匹配。

## 验证

测试：`PortableArchiveTest`、`TransferWireTest`、`TransferUiTest`、`AppDatabaseMigrationTest` 和现有分享回归。截图保存在 `artifacts/device-transfer/`。协议回环测试覆盖完整分块、尾块、确认偏移、损坏和截断控制消息；它不替代 Android 真机无线链路测试。

后续真机验收仍需在两台不同品牌安卓设备上验证：同 Wi-Fi、热点、无路由器 Wi-Fi Direct、切后台、断线重连、进程重启续传、通知取消，以及微信／QQ／系统文件分享的冷启动接收。当前工作环境未连接真机，因此这些项目和真实双机录屏尚待完成，不能将界面状态截图作为无线实测证据。
