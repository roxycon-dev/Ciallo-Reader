## 指定单本的实际结论

《无职转生未来日记》不是两个书名。2026-10-19 在 z-library.website 和 z-lib.by 分别实测：完整标题均只命中 1 张明确隐藏的同名书卡，真实可见同名结果为 0。该隐藏书卡的作者也复制查询词，书号和格式随请求变化，旧客户端误将它展示为可下载；另用完整书名逐一检查，两节点详情与文件接口均返回 HTTP 204 空响应。

已修复误解析，并通过两节点 Android 实网测试：隐藏卡不会再作为可下载结果出现，可见同名版本仍会保留。**这解决了虚假条目导致反复下载失败的客户端缺陷，但尚未取得这一本的有效文件，不能声称它已下载入库。** 正在等待具体详情链接或作者名以继续核对有效版本。

## 修复内容

- 布局选择前统一剔除 hidden、aria-hidden=true 与内联 display:none / visibility:hidden 子树，通用兜底也不重新引入；不根据标题或作者猜测过滤。
- 保留搜索卡直链与实际来源，传统数字书号直接提取 API ID/hash；下载身份与登录会话保持一致，第三方 CDN 不接收来源 Cookie。
- 节点按直连优先探测，失败后使用系统代理；失败节点排除并冷却五分钟，成功节点持久化。下载链接失效会自动重新匹配书名、作者及格式，避免把另一版本下载成原书。额度、频率和存储错误停止自动换线。
- 修复根目录 OPF 的 EPUB 入库：旧目录解析把空目录与 `/` 拼接成 `/toc.ncx`，被路径检查拒绝；现在只在非空目录后追加分隔符，保留原有解压和正文路径边界校验。
- 书库有文字“下载任务”入口和常驻可点击进度条；面板显示准备、百分比、字节量、失败原因、文件明细，并提供暂停、继续、取消和重新获取链接重试；小说与漫画同时展示。
