# 多语言搜索 v3 与上游 1.2.1 合并

这轮针对三个实际反馈：开关已开却显示未启用、开关说明文字被遮挡、搜索用词占据固定区域。资料查询仍采用本地优先、缺少或语言不全时在线补充并缓存；普通关键词发给书源，诚实展示书源返回结果。

## 已实现

- 修复搜索补词的错误门控。`PrivacyManager.isEnabled()` 表示书架分类 PIN 保护，不能据此全局禁用书库名称查询。全局无痕浏览仍暂停在线补词和词典更新，并明确显示“无痕浏览中，在线补充暂停”；关闭开关显示“在线补充已关闭”。翻译路径未改。
- 已有搜索时开启在线补词，会重新执行已提交的查询，避免继续显示上次关闭时的状态；不会拿输入框中尚未提交的草稿去重新搜索。
- 移除多语言选项的固定 56dp 高度，两个开关行按实际说明文字自适应。在线行与上方文字对齐，大字体与窄屏不会压到下一行。
- 搜索用词改成玻璃卡片、名称标签、数量与状态。默认收起，标签可横向浏览；展开显示完整名称、来源、交给书源的数量，名称可长按复制。
- 聚合搜索的卡片是瀑布流首个跨列条目；单源、等待、失败和无结果状态也放在结果滚动区域。向下浏览就滚走，回顶能再次查看。展开长名称由结果列表统一纵向滚动。
- 书源速跳、当前组判断和流式定位加入首部关键词条目的偏移，保留分组展开与加载占位的定位计算。

## 验证与验收

最终结果以 `artifacts/multilingual-search-v3/verification.json` 和原始测试 XML 为准：

- 核心专项覆盖名称补齐、在线缓存、PIN 不误伤搜索、无痕停用原因、开关读写、取消、复合查询、聚合调度、速跳偏移及上游作者对象兼容。
- 六项 Compose Native 测试覆盖原词唯一 / 失败反馈、在线到达即时显示、长名称、聚合跨列卡片滚走和回顶、单源滚动、320dp 与 1.5 字体比例下的开关布局。
- 界面截图使用生产关键词组件与生产 Lazy 列表条目函数，外层搜索框和结果为测试容器；不是用户手机或完整书库页实拍。
- Android 设备测试需编译确认。本轮不把编译成功当成真机运行通过，也不声称在 E-Hentai 登录账号上验证了结果命中率。

安装同证书的验收 APK 后：开启多语言与在线补词，使用本地未收录的角色 / 作者名；查看状态、外文名称和提交数量。关闭再开启在线补词，现有查询会重新查词。开启全局无痕时应显示暂停原因。向下浏览漫画，关键词卡片应离开屏幕，回顶重新出现。将字体调大，两个开关说明应完整显示。
