# Ciallo Reader 1.5.7 · 启动兼容与完整诊断

版本 **1.5.7 / 249**，Android 7.0+，ARM64。

## 启动与主页兼容

- 针对“点击开启阅读或跳过后退出，再次打开仍退出”的路径，修正旧系统的主页渲染兼容处理。不支持 RenderEffect 的系统使用现有磨砂替代样式，不再开启无效的实时背景采样。
- 将 Android 13 专用 RuntimeShader 的类型与操作从通用玻璃卡片入口隔离到受版本检查保护的独立实现，避免旧系统解析通用入口时接触不存在的平台类型。可选着色器被驱动拒绝时使用现有替代绘制路径。
- 主页进入早期发生实际 Java/Kotlin 渲染异常时，同步保存兼容画质，让下次启动避开高级渲染路径；原始异常继续交给 Android 处理并保留本地诊断，不在崩溃后的界面上继续运行。
- 恢复不会清空书库、阅读进度、书源、登录信息或引导状态。正常重启、无关后台错误和窗口外异常不会触发画质恢复。

反馈者补充的“断网、关闭纯洁模式后仍退出”不支持把问题只归因于联网或风险提示。当前没有反馈机型和崩溃堆栈，**未在 HarmonyOS 3.0 原机复现或确认根治**；具体排查与验证范围见 [技术记录](harmony-home-entry-2026-10-26.md)。

## 诊断导出

「设置 → 关于 → 导出启动诊断」改为带图标的完整按钮，移除原来的说明小字。点击后可选择文件保存位置，生成与写入在后台执行。

日志包括应用版本与 APK SHA-256、设备/系统构建、屏幕与字体、内存和存储、异常消息与异常链、suppressed 异常、线程状态和堆栈、页面路径、引导操作、启动任务起止与结果。保留最近多次异常及上次进程轨迹，最后一次崩溃独立保存，不被普通启动错误覆盖。

Android 11+ 还会附上本应用可获得的系统退出原因、内存统计及系统提供的 ANR/native 线索。旧系统可能无法提供这些底层记录。日志有容量上限并对凭据、URL 与私人路径脱敏，不自动上传；需要使用本 Release 同次构建的 mapping 文件还原混淆堆栈。

## 权限与升级

- **现有权限与功能保留**：不移除 Wi-Fi Direct 所需的位置/附近设备权限，不取消开机后恢复任务或相关唤醒能力；同 Wi-Fi 互传、后台下载、朗读及用户确认后的系统安装功能保留。
- 成人源及默认启用逻辑保留；1.5.6 的 TLS 与新固定签名修复保留。本版未进行新的查杀复测，不能保证系统“不良软件”等分类已变化。
- **1.5.6 可直接覆盖升级**。1.5.5 等旧签名版本仍需按 [签名迁移说明](app-signing.md)先导出备份、确认文件可读，再迁移安装与导入，不能直接覆盖旧签名。

## 验证范围

31 项单元与原生图形回归通过，覆盖 API 28 / 30 的主页、卡片类型解析与绘制，以及现代系统可选着色器的拒绝回退。现有 API 30 模拟器上的 3 项设备流程检查通过；确认无活动默认网络后，追加的 3 项断网检查同样通过。没有新增模拟器或系统镜像。正式包完成 R8、Vital Lint、固定证书验签及 ZIP 对齐校验；测试结果不能替代 HarmonyOS 3.0 原机验收。
