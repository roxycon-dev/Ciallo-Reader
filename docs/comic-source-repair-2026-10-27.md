# 漫画源搜索、阅读与下载验收（2026-10-27）

本次最终验收只重测用户指定的 **紳士漫畫、19漫画和爱漫画**。其他已经通过的源不重复运行。用户确认按本次修复和已有验证结果发布，Picacg、vomic、MYCOMIC 的登录或网站验证要求保留，不将它们计为通过。

## 修复与原因

- 爱漫画部分正文经 WordPress 图片代理返回 HTTP 400，同一原图可读取。正文与旧缓存图片地址改用源站公开原图，封面及无关域名保持原路径。
- Android 系统代理可能保留在 `global_http_proxy_host/port`；单独删除 `http_proxy` 项并不会清除实际代理。此前部分“直连”重试仍经过该代理，造成误判。相同设备的对照请求证实：19漫画通过代理会在响应头阶段断流；爱漫画图片经过代理会出现 gzip CRC/解压错误，而真正直连能完整取得并解码。
- 三个指定源的公开 GET 优先使用带证书校验的直连，完整读取后确认成功，再按需尝试系统代理和 Chromium。爱漫画图片同样优先直连，响应体损坏在路由选择阶段处理，限制单图读取量并保持取消控制。
- 紳士漫畫有可用配置域名时不再等待域名发布页的启动刷新；手动刷新和缺少可用域名时的初始化仍保留。
- 包含本任务已完成的聚合搜索期限和错误状态、下载请求头、续传旧文件、拷贝源初始化及逐源缓存故障隔离修复。

修复前还做过真正直连对照：三个源同样完成共91页全新下载和离线读取。非压缩与短连接实验未解决代理损坏，实验性请求头已撤回。

这些结果对应表中真实章节和验收时的线路。搜索没有结果不等于网络失败；已下架、需要授权或原站缺失图片仍保留明确错误。爱漫画另一作品“预告”的原站缺图未伪装成下载成功。
