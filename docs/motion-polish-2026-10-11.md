# 动效与阅读设置玻璃材质调整

本轮依据 `motion-audit-2026-10-11.md` 实施，并优先处理书架重排、补位、筛选和两套阅读器设置的材质。

## 书架

- 删除可见书卡时，截取实际书卡，拆成 48 个不规则三角碎片；碎片向外散开、旋转、下落并淡出，总时长约 660ms。其它书立即开始平滑补位。
- 本地书架和首页收藏网格接入稳定 key 的入场、退场和位置动画。排序使用阻尼 0.88、刚度 210 的弹簧；筛选保留的书移动到新位置，移除和新增条目分别淡出、淡入。
- 点击排序前保留网格的索引与滚动偏移，防止原来第一本书变成排序后的滚动锚点。拖拽时停用额外的位置动画，交给现有拖拽宿主控制。
- 批量操作最多为 8 张可见卡片生成碎裂效果。离屏条目、减少动态效果模式和快照不可用时仍正常执行删除。
- 快照等待期间保留原书卡；重复确认不会重复执行同一轮删除，退出页面或取消快照协程也不会丢失已确认的操作。隐私锁开启时停止绘制书卡及其残留碎片。
- 移除书架原先持续上下浮动的循环。

## 阅读设置

- 小说的显示区、文字排版区、字号步进器、翻页模式选项改为分层玻璃；主题预览仍显示实际纸张颜色。
- 漫画的分组卡片、横向和侧边分类导航、模式和方向选项、预设入口、引擎卡片、开关轨道使用统一的玻璃材质。
- 内层玻璃直接采样原始阅读内容，使用模糊、半透明主题色、柔和高光和细边框，文字和图标保持清晰。
- 漫画仿真翻页的页面位于独立 GL Surface。设置打开时用当前页的已处理位图建立专用采样层，不把 GL 视图挂到 Compose 捕获层；支持单页、双页、旋转、裁边和图像处理后的缓存。
- 关闭漫画面板后短暂保留采样源，覆盖完整退出动画；阅读时释放采样层。平板与横屏面板从右侧出现，手机面板从下方出现。漫画设置、预设、目录、裁边之间增加内容转场。

| 小说插图 | 双击围绕点击位置平滑缩放，缩放与平移同步收敛；手势可中断缩放，打开和关闭有短过渡。 |

| 卡片与搜索 | 各画质档保留轻量按压反馈；移除卡片因滚动重新组合而重播的入场；缩短搜索历史的展开与收起。 |

| 减少动态效果 | 监听系统动画设置变化，新加的碎裂、位移、面板、插图、主题等效果接入降级。 |

## 验证与预览

测试覆盖碎片覆盖面积、删除补位中间位置、排序视口、重排中切换筛选、重复确认、取消协程、弹层退出、日夜切换中间帧对比度，以及两套设置在手机和平板上的控件操作。另复测开屏生命周期、底栏动效、漫画手势、设置功能、关键词卡和导航。

截图位于 `artifacts/motion-polish/`：`shelf-before`、`shelf-fracture`、`shelf-after`、`shelf-reorder`、`shelf-sort-settled`、`shelf-filtered`，以及小说、漫画的手机与平板设置截图和漫画仿真模式采样预览。

验证环境为 Robolectric / Android 34。该环境不能截取包含 GPU RenderNode 的书卡快照，所以碎裂测试注入了同一真实测试书卡的截图像素，执行正式的碎裂绘制和删除逻辑；产品运行仍使用 GraphicsLayer 快照。尚未连接 Android 真机，GPU 快照、实际毛玻璃效果和连续操作的帧率需要在设备上验收。

最终结果：截图录制和普通测试两种运行方式均通过 11 个测试类、40 项测试，失败、错误和跳过均为 0；`:app:assembleDebug` 成功，`git diff --check` 通过。像素采样测试显式截取当前帧，避免普通测试读到上次遗留的截图。

调试安装包：`artifacts/motion-polish/CialloReader-motion-polish-debug.apk`（约 44.8 MiB）。构建日志为 `verification.log`，普通测试日志为 `default-test-verification.log`，逐测试结果保存在 `regression-results/`。
