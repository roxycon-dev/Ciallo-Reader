# Ciallo Reader 1.6.5

2026 年 11 月 19 日 · 构建号 266 · Android 7.0+ · ARM64

## 更新下载修复

- 「设置 → 关于 → 检查更新」和启动时的自动检查使用同一个下载面板，可以选择 GitHub 或国内 HTTPS 镜像。
- GitHub API 限流或缺少 APK 摘要时，从同一 GitHub Release 的 `SHA256SUMS.txt` 获取校验值。镜像安装包仍需通过完整性、包名、版本和签名检查。
- 已安装 1.6.5（265）的用户可从 GitHub Release 下载 266 并覆盖安装。旧更新器按版本名判断，同名修订需手动下载安装一次。

## 小说和电子书

- EPUB 读取书内样式表和行内样式，尽量保留标题、粗体、斜体、下划线、删除线、上下标和竖排等常见排版。DOCX、FB2 和 MOBI 系列也会保留支持的文字样式。新增 Markdown、HTML 和 XHTML 导入，直接渲染正文。
- 本地小说可按书籍设置横排、竖排或随原书排版。竖排支持两种列方向、插图和阅读进度。
- 长按正文可调整选区、复制、查词，或添加高亮、下划线和范围批注。支持将选段、书名和章名导出成「阅读时刻」PNG。

## 听书和词典

- 本地与在线小说使用统一听书面板，支持 Android 系统语音、Edge 在线音色和自定义 HTTP 语音接口。从阅读位置或指定段落起播，可调语速、音调、段落间隔和定时停止。
- Edge 与自定义语音可按 15 秒快退或快进。后台媒体服务支持从锁屏和通知控制播放，章节结束后可续听下一章。
- 可从阅读器打开词典，也可长按正文直接查所选词。可导入 StarDict、MDX v1/v2（未压缩或 zlib）及带可读词头或显式词条的 MOBI/PRC 词典。释义支持离线查询。
- 听书、词典和横竖排设置沿用 Ciallo 主题和按压反馈，并读取减少动态效果与极简画质设置。

## 验证范围

Android 30 模拟器验证了 EPUB 外链 CSS 粗体和实际竖排、本地及在线阅读入口、正文选段查词、Edge 真实音频、自定义语音快进和熄屏跨章。StarDict 在 Android 上实测导入，MDX/MOBI 通过测试夹具验证。不同厂商的锁屏和后台策略仍待真机实测。逐项记录见 [阅读器交互验收](WENKU_INTERACTION_AUDIT.md)。

正式 ARM64 APK 通过 v2/v3 验签，沿用正式发布证书。在 Android 30 模拟器完成从 1.6.5（265）到 1.6.5（266）的覆盖安装并打开应用。
