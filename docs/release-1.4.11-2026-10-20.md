# Ciallo Reader 1.4.11 / 234

小说与漫画阅读器新增统一的触控功能分区，弹层与滑动条采用公共动效组件。

## 使用入口

- 小说：阅读状态栏 → 排版设置 → 自定义触控功能分区。
- 漫画：阅读设置 → 手势 → 可视化编辑功能分区。
- 编辑直接覆盖当前小说 / 漫画，不开新窗口、不缩小页面。轻微暗色蒙层上显示区域边界与功能；工具可收起或移到另一侧。“试读”临时隐藏编辑辅助，用未保存的配置体验真正的翻页，返回后可继续调整。
- 添加矩形后可拖动移动、拖动四角缩放，或置顶 / 删除。重叠区域由最上层同时接管点击和滑动；空白区域不执行自定义动作。
- 点击与滑动独立选择。滑动翻页显示范围条、流动虚线及模拟手指；选择校准后在选中区域自然滑动一页，之后仍可拖动范围条端点或滑动条微调。
- 保存后生效，取消保留原配置。恢复默认移除覆盖并沿用原有阅读引擎和参数；漫画预设和每书配置包含自定义分区。

## 统一组件

`LiquidSlider` 使用原生 Canvas 实时绘制轨道、液体和玻璃透镜，沿曲线采样 96 点，支持连续、分档与双滑块范围，保留纵向页面滚动、读屏调整和深浅主题。

`PullOutSurface` / `PullOutVisibility` / `PullOutDialog` / `PullOutBottomSheet` / `PullOutDropdownMenu` 共用 `PullOutConfig`。按钮自动记录屏幕矩形与纹理，纸面使用 26×150 的密集二维网格；开关共用形变路径与不同弹簧。纹理 alpha 保留圆角，软件超采样处理边缘。漫画玻璃背景直接绘制当前页处理位图，纸面转换位图后释放记录引用，避免跨树渲染节点循环。减少动态效果、极简模式和纹理失败使用公共降级。
