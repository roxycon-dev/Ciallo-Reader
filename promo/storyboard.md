# Ciallo阅读｜宣传片镜头方案（待实机素材核对）

## 制作设定

- 72 秒，1920×1080，30 fps，16:9；若实机素材质量和渲染性能允许，再输出 4K 版。
- 主线：发现 → 收进书架 → 漫画沉浸 → 小说沉浸 → 品牌与下载。
- 漫画阅读 22–43 秒，小说阅读 43–52 秒；漫画占阅读段 21/30 = 70%。
- 当前 v1.1.0 实机画面是唯一 UI 画面依据；镜头外的环境光、玻璃折射、排版与设备外框属于影片视觉设计。不得绘制不存在的 App 界面、放入旧截图或 AI 漫画。
- 字幕仅四组短句，中英双语；片头品牌字标及片尾 CTA 不计作功能字卡。文案为创意提案，最终以实机画面节奏微调断句。
- 音乐：稀疏氛围钢琴 + 低频脉冲。拟音突出呼吸、触碰、滑动与玻璃边缘；每次关键操作只保留一个清楚的声音事件。

| 功能汇聚与收尾 | `outro-group-photo-launch` | 单机位产品定格 | 多个已采集的真实页面以独立手机画面汇聚，最后归一到品牌和两个 CTA。 |

## 素材与真实性检查点

1. 演示包优先使用独立包名和独立数据；采集前检查屏幕，若有私人书架、账号、历史或通知，立即停止并移开内容。
2. 搜索/下载镜头要拍到真实可重现的因果过程。无法安全演示时，在分镜中改名为「导入书籍」，字幕和画面同步更改。
3. 漫画正文需有宣传片可使用的授权或公共领域来源；不得引用 AI 漫画旧草图。
   候选为 David Revoy 创作的 [《小辣椒与萝卜头》第 28 集官方中文页面](https://www.peppercarrot.com/cn/webcomic-sources/ep28_The-Festivities.html)（漫画页 CC BY 4.0，中文翻译 Ran Zhuang）。若采用，按该集官方署名信息在片尾或发布说明中署名；具体篇章以实际导入效果为准。
4. 片尾 APK 地址使用项目实际可访问发布页。若录制时暂无发布页，保留地址文案但不上虚构二维码。
5. 视觉关键帧先以当前手机的安全实机截图重做，再让用户审阅分镜和关键帧。通过后进入完整录制、Remotion 制作与成片渲染。

## Gallery 对照

所选卡来自 `video-shotcraft/gallery/api/library.json`。后续实现逐一卡片读取其源文档和 demo，沿用原卡的时值、缓动与遮罩参数，再将当前 App 实机画面代入。实机阅读操作优先服从录屏，不强行套用 Gallery 动效。
