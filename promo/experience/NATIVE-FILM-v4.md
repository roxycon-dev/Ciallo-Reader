# Ciallo阅读 · 实机速览版

## 已采纳的最新要求

HTML 是宣传片载体；所有功能自动呈现，画面内无“试试看”按钮。保留原应用 UI 像素，周围的标题、舞台、粒子属于影片包装。新录屏已收录为 `promo/user-footage/12_history_stats.mp4`。

自主推进。采用现有 HTML 引擎与实机关键状态剪辑，未套用某张 Gallery 卡，因此没有卡片还原度声明。用户要求加快节奏，覆盖 skill 默认的长停留建议；大部分功能每 1.6–2.5 秒切换，每镜内还有真实 UI 状态切换。更改仅限 promo。

## 素材原则

- 所有产品界面都是原视频整帧或自然裁切，没有重排、替换正文、补画控件、合成数值或人工打码。
- 展示明确为实机关键帧剪辑；摄影式运镜和切换不代表原生 App 帧率。
- 下载使用实际 97%、已暂停、已完成三种原始状态。
- 小说使用原始阅读页的安全段落裁切和真实排版面板；Roxy 使用真实“书签已保存”弹层。
- 新统计素材原始分辨率 432×960，采用三联全屏视图，避免极端放大，不 AI 修复或伪造数据。
- 阅读统计数值属于录制时的个人示例，不将其当成产品能力指标。
- 不夸大翻译效果；镜头只展示真实翻译/OCR 配置。

## 自动覆盖的功能

多源聚合、漫画/小说分类、多语言搜索、自定义 JSON 书源、书源启停、跨源结果、章节选择、在线阅读、下载管理/暂停/完成、书架分类、本地导入、多种漫画阅读模式、阅读方向、画面调节、翻译/OCR 设置、自动翻页/手势、小说字号/行间距/页边距/主题、书签反馈、主题/强调色、玻璃控件、继续阅读、阅读日历、趋势、时段与周统计。

确切镜头顺序与时长只在 `native-film.js` 的 SHOTS 数组维护，播放器、章节导航、录制模式和截图定位共用。

## 录制与交互

默认自动播放，支持暂停、前后镜头、进度拖动、倍速、音乐和全屏。`?record=1` 隐藏播放器与浏览器内周边文字，保留纯 16:9 舞台；空格控制暂停，左右方向键切镜头。`window.CialloPromo.seek(seconds)` 可定位关键帧，`duration` 为总时长。`?frame=seconds` 打开指定定格，便于核对。

以原 Ciallo 薄荷绿、暖色强调、黑白漫画与玻璃素材为色彩依据。字幕与界面外包装继承上一版已获用户认可的字体、对比和留白；原生界面内部保持完整。
