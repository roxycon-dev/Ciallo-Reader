# Ciallo 阅读 / 下一页，按你的方式

## v5：38.6 秒，18 镜头

这次重做镜头结构。用短促的漫画与小说字卡打断节奏，在多源空间展开、横向搜索、满屏漫画、设置轨道、小说留白、下载收纳、主题色场、玻璃特写和阅读统计之间切换。单镜 0.65–4.8 秒，主要动作各有自己的速度和方向。

所有 App UI 均来自用户录屏整帧或自然裁切，不重绘、不模拟数据、不打码。漫画分镜采用实机内容的自然裁切；翻译只展示设置。录制中的卡顿不进入主片，包装动画不代表原生 App 帧率。

## 打开 / 录制 / 互动

- 直接打开 `promo/output/Ciallo-reading-experience.html`，图片、字体和可选声音全部内嵌，可离线播放。
- 项目预览：在此目录运行 `node server.mjs`，访问 `http://127.0.0.1:4173/?v=5`。
- 默认静音自动播放，结束后停在真实下载入口；点击 ♫ 开启钢琴与少量转场拟音。音乐最后淡出。
- 空格暂停或重播；左右方向键切镜头；进度条定位；1× / 1.25× / 1.5× 倍速。
- 按 H 隐藏控制条；`?record=1` 直接进入纯画面模式；建议全屏 1920×1080 录制。
- 鼠标进入画面时，粒子轻微让开；片尾下载链接通往软件 GitHub Releases。
- `?frame=32.8` 定格；`window.CialloPromo` 提供 seek、play、pause、duration、shots。动画由影片时间驱动。
- 页面隐藏时暂停；首次加载到后台会在第一次显示时开始。系统启用减少动态效果时初始暂停，禁用粒子和主要相机变换。

## 内容与素材

多源聚合、漫画 / 小说 / 多语言、书源管理与 JSON、搜索结果、作品详情与章节、在线阅读、漫画模式 / 方向 / 图像 / 翻译 / OCR / 自动翻页 / 手势 / 背景、小说排版与主题、书签、下载中 / 暂停 / 完成、书架分类与本地导入、主题与强调色、玻璃质感、继续阅读、阅读时长 / 日历 / 趋势，以及公益开源下载入口。

`DIRECTOR-v5.md` 记录镜头决策；`native-manifest.json`、`kinetic-manifest.json` 和 `ASSETS.md` 记录来源。统计录屏为 432×960，不伪造高清细节。声音来自原项目的钢琴与既有 Mixkit 资源，出处见 `AUDIO-ATTRIBUTION.md`。

## 编辑与打包

`kinetic-film.js`：时间轴、独立镜头模板、播放器与音效点。`kinetic-film.css`：镜头构图与时间驱动动画。`python build.py` 生成离线 HTML 和源码 ZIP。修改仅限 promo，旧版文件存于 `archive-v4/`。

`review-v5/` 保存静帧与一遍完整 960×540 / 24fps 无声运动预览，用于视觉检查，不是最终清晰度上限。
