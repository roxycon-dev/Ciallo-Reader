# Ciallo · 给自己，一页的时间

## 导演决定

自主创作；用户要求按动画短片制作，形成情绪牵引，同时保留紧凑节奏、全部重点功能、实机 UI、完整自然裁切和互动。最新额度下限 45%。使用自编 HTML 时间轴，未指定 Gallery 卡片。

主线：一束光从合拢的书页透出，寻找故事；阅读世界展开后，画面与文字让人沉进去；最后光回到书页，阅读记录与继续阅读承接「故事为你留着」。片头和片尾呼应。没有旁白，以字幕、画面和原创音乐叙事。

## 三幕及信息分配

1. 寻找（0–12.15s）：开页 3.1s、多源 3.3s、源管理 1.5s、跨源搜索 2.5s、详情章节 1.75s。
2. 沉浸（12.15–28.95s）：漫画字卡 .55s、漫画阅读 2.7s、六项阅读设置 4.8s、小说转折 .75s、小说排版 3s、书签 1s、下载三状态 2.4s、书架与导入 1.6s。
3. 留住（28.95–41.35s）：配色 2.3s、玻璃 2.2s、统计日历趋势 2.7s、继续阅读 2.4s、品牌落幕 2.8s。

## 视听语法

- 使用原软件的青绿、玻璃、纸色。黑色深景承担寻找与沉浸，纸色承担小说阅读，暖光承担回到故事。
- 主体处于 8% 安全区；原图按自然比例完整放入，书源、章节、下载卡重取干净边界。漫画人物保留完整素材边界，背景建筑允许作为环境近景。
- 镜头各有目的：开书→空间拉开→搜索会合→章节近景→漫画分镜展开→设置快速经过→小说静下来→收藏收拢→玻璃掠光→阅读足迹→回到书页。
- 不再用同一种平移入场；切点采用动作匹配、短叠化和黑场呼吸，重要 UI 的停留区间稳定可读。装饰光只在背景，不盖住 UI。
- 原创钢琴主题加入克制的低音与柔和长音，按三幕改编；小说段收掉节奏，末段回归片头旋律。声音点击开启，浏览器静音自动播放。
- 互动保留播放、定位、倍速、全屏和粒子响应；功能自动演示，不依赖观众点击。

## 素材与审阅

仅使用用户实机录屏的整帧、自然裁切及包装图形；小说使用既定安全文本片段。来源见 native-manifest.json、kinetic-manifest.json、composition-manifest.json。无重新录手机、无模拟 UI、无打码。

最终以离线 HTML 为正式成品，同时保存完整运动预览和关键帧；按 video-shotcraft 进行一次干净上下文独立视觉终检。独立审阅覆盖静帧与代码，未发现有证据的必须修复项；连续运动和主观音质不在该审阅结论范围。制作回看额外修正了下载浮层在回拖时间线后的残留，以及收尾 UI 叠影（改为短暂暗场过渡）。统计素材分辨率较低，按原始细节呈现。
