# Ciallo阅读 · 50 秒自动演示 + 可操作功能体验

打开 `index.html`，默认静音自动播放。无需安装依赖。也可打开 `promo/output/Ciallo-reading-experience.html`，这是图片、字体、音乐全部内嵌的单文件版本。

## 观看与操作

- 首屏自动展示：多源搜索、漫画阅读器、小说阅读器、离线下载、阅读记录、玻璃界面。
- 底部可以暂停、继续、重播、跳章节和全屏。播放结束停在应用入口。
- 左下角开启音乐；声音默认关闭。
- 点击“亲手探索”或场景按钮，可进入对应功能。滚动、触摸滑动或切到后台会暂停影片。
- 漫画场景可以手动翻页，小说场景可以调整演示字号与纸色。
- 系统开启“减少动态效果”时默认暂停演示并关闭粒子效果，可手动切章节。

## 一条可以实际走完的阅读流程

1. 搜索「星灯」或「无职转生」，切换漫画／小说或示例书源。
2. 打开作品、翻页或切章；小说可改变字号与背景。
3. 加入离线列表，暂停或恢复下载流程演示。
4. 下载完成后，切为“模拟离线”，打开已完成的作品。
5. 从阅读记录继续上次进度。记录只保存在当前浏览器；不会接触手机或 Android 应用数据。

下方还可以拖动玻璃卡片、调整通透程度、与 Roxy 打招呼，以及查看未经人工打码的真实应用截图。

## 素材与真实性

实际界面来自用户提供的手机录屏，选用清晰静帧；浏览器生成连续动效，不重放原片卡顿、加载等待或异常翻页。没有 AI 漫画、人工马赛克或旧版应用截图。

自动影片与交互控件是宣传演绎，书源和下载状态为示例；并非网页中运行着 Android 应用。原始素材记录见 `asset-manifest.json`。新增画面由 `prepare_feature_assets.py` 提取，旧资产由 `prepare_assets.py` 提取。

## 本地服务与打包

```powershell
node server.mjs
```

打开 `http://127.0.0.1:4173`。服务只绑定本机。运行 `python build.py` 可生成单文件 HTML 和完整目录 ZIP，未发布到互联网。

- `index.html`、`experience.css`、`cinema.css`、`experience.js`：当前网页。
- `DESIGN-v3.md`：节奏、动效、功能与源码依据。
- `review-v3/`：当前版本的桌面、手机渲染截图。
- `archive-v1/`：旧版静态叙事页面备份。旧 `review.mjs`、`review-offline.mjs` 和 `review/` 属于该旧版，不适用于当前 DOM。

技术与视觉记录不等同于用户对最终效果的验收。
