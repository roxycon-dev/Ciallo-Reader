# Ciallo阅读 · 交互宣传体验

打开 `index.html` 即可离线浏览。所有图片、字体和音乐都在 `assets/` 中，不依赖 CDN 或外部脚本。保持目录完整即可分享。

## 观看方式

- 自由滚动：漫画从画框展开，滚动决定画面进程。
- 自动演绎：点击底部的播放按钮，约 89 秒走过整段体验；滚轮、触摸或方向键会立即暂停，可以随时继续。
- 声音默认关闭，点击扬声器开启原创钢琴背景音乐。
- 全屏按钮可以在支持该功能的浏览器中进入全屏。
- “质感”章节的书架、阅读、玻璃与排版按钮切换不同的真实实机画面，可使用方向键操作。
- 点击“和 Roxy 打个招呼”可以看到应用原有的另一张 Roxy 形象。

## 素材与流畅度

这次从用户提供的录屏中选取稳定、清晰的静帧，以浏览器变换生成连续运镜。原录屏中的卡顿、页面加载、异常翻页和误操作不进入展示；页面没有循环播放这些片段。实机画面没有人工打码、模糊或 AI 补画。

这是一份艺术化的产品展示，界面切换展示的是实机截图，而不是运行中的 Android 应用。原始时码及裁切记录见 `ASSETS.md` 和 `asset-manifest.json`。

## 本地预览

如需通过本地服务器观看，在本目录执行：

```powershell
node server.mjs
```

然后打开 `http://127.0.0.1:4173`。这只是本机预览，没有发布到互联网。

## 文件

- `index.html`、`experience.css`、`experience.js`：完整静态页面，无运行时第三方依赖。
- `assets/`：真实截图、原有角色、应用字体和压缩后的原创音乐。
- `prepare_assets.py`：从原始实机素材重新提取资产。
- `review/`：桌面与手机截图、浏览器检查结果。
- `review.mjs`：浏览器检查脚本，使用工作区已有的 Playwright 与 Chrome；不影响页面运行。
