# Ciallo 阅读 · 36.2 秒实机速览

18 镜头自动播放。产品界面全部来自用户录屏的整帧或自然裁切，外部标题、粒子、运镜为影片包装。没有重绘 App UI、模拟数据或人工打码。此前 50 秒版本保留于 `archive-v3/`。

## 打开与录制

- 直接打开 `promo/output/Ciallo-reading-experience.html`，完全离线；默认自动播放，音乐默认关闭，点击 ♫ 开启。
- 项目预览：在此目录运行 `node server.mjs`，访问 `http://127.0.0.1:4173/`。
- 录制入口：`http://127.0.0.1:4173/?record=1`，或播放时按 H 隐藏播放器。建议全屏 1920×1080 录制。
- 空格暂停 / 重播；左右方向键切换镜头；进度条定位；1× / 1.25× / 1.5× 倍速。
- 默认播放一遍后停在结束画面；隐藏页面时暂停。系统启用减少动态效果时，初始暂停并关闭粒子和镜头变换。
- `?frame=32` 打开指定时间的定格。`window.CialloPromo` 提供 seek、play、pause、duration、shots。

## 镜头覆盖

多源聚合 → 书源管理 / JSON 导入 → 搜索 → 详情 / 章节 / 在线阅读 → 下载中 / 暂停 / 完成 → 书架 / 本地导入 → 漫画阅读 → 阅读模式 / 方向 / 图像 → 翻译与 OCR 设置 → 自动翻页 / 手势 / 背景 → 小说排版 → 书签 → 主题 / 强调色 → 玻璃质感 → 继续阅读 → 时长 / 阅读日历 / 趋势 → 片尾。

新增录屏已纳入 `12_history_stats.mp4`。该素材为 432×960，按原始清晰度展示，不合成高分辨率 UI。翻译镜头展示设置，未声称演示实际译文；下载进度及统计数值都是录制时的真实示例。

## 素材与打包

`native-manifest.json` 记录新镜头的原视频、时间点、裁切范围。旧素材溯源见 `ASSETS.md`。关键帧跳切避开原录屏卡顿，影片运镜不代表 App 原生帧率。

执行 `python build.py` 重新生成离线 HTML 和可编辑 ZIP。无需安装 npm 依赖。界面内容可能随软件版本变化。
