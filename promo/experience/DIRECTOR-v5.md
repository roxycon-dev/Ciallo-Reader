# Ciallo 阅读 / 下一页，按你的方式

自主创作，延续用户已授权方向。v4 的问题是匀速切换说明卡，缺乏视觉预期变化。v5 以“发现 → 沉浸 → 自由 → 留下足迹”组织功能，将同一种布局与同一种主动作的重复次数降到最低。用户指定快节奏优先于 skill 默认长停留。

## 视觉与动作

真实截图像素保持不变。包装沿用应用的薄荷绿、橙色、暖纸色与玻璃层次，Arial / Microsoft YaHei，标题粗体。画布 1920×1080；网页仍然是可暂停、定位、重播、全屏的影片。用户要求的“互动”用于播放、粒子响应与片尾真实下载链接，不模拟 App 控件。

选用自定义原生 DOM/CSS/Canvas 镜头，不套 Gallery 配方卡：多源展开、实机面板放大、横向检索、满屏漫画、设置输送带、安静的小说留白、下载状态聚焦、色场切换、玻璃折射、真实统计轨迹。每个主动作只承担一个段落。真实截图、裁切和溯源沿用已核对素材；无需重采手机。

动作参数：主要动作 0.45–0.8 秒，四次缓入缓出长移动；快速插镜 0.65–0.9 秒；重点 2.4–4.8 秒。快切、揭幕、横向擦除、圆形展开与纸页式切换交替。每次切入保留上一镜头底图，避免空白闪烁。静音自动播放，音频可选。
